ПЛАКАТ 51: ЗНАЧЕНИЯ СЛОВ

Прямое и переносное значение. Синонимы и антонимы.

1. Прямое и Переносное значение (у многозначных слов)

✅ Прямое значение

Это основное, "родное", первичное лексическое значение слова. Оно прямо указывает на предмет, признак или действие.

Примеры:

золотое кольцо (сделанное из золота)

каменная стена (сделанная из камня)

ледяная глыба (состоящая из льда)

🔄 Переносное значение

Это вторичное значение, которое возникло в результате переноса названия с одного предмета на другой на основе их сходства.

Примеры (по сходству):

золотые руки (по цвету? Нет. По ценности, как золото)

каменное сердце (по твёрдости, "непробиваемое")

ледяной взгляд (по холоду, "недружелюбный")

2. Отношения между словами

🤝 Синонимы (Близкие)

Слова одной части речи, близкие по значению, но разные по написанию.

  • 💡 Помогают избежать повторов и сделать речь точнее.

Примеры:

Смелый - храбрый, отважный.

Метель - вьюга, буран, пурга.

↔️ Антонимы (Противоположные)

Слова одной части речи, противоположные по значению.

  • 💡 Используются для контраста, противопоставления.

Примеры:

День - ночь

Хороший - плохой

Друг - враг

ГЛАВНАЯ МЫСЛЬ

У слова есть прямое ("обычное") значение и может быть переносное (возникшее по сходству).
Синонимы - слова-"друзья" (близкие по смыслу). Антонимы - слова-"спорщики" (противоположные по смыслу).
