☁️ «Бұлт» дегеніміз не? ☁️ What is «the cloud»? ☁️ Что такое «облако»?

Бұлтты есептеу (Cloud Computing) — мәліметтерді өзіңнің ноутбугыңда емес, Интернет арқылы қашықтағы үлкен дата-орталықтарда сақтау және өңдеу. Терминді 2006 жылы Google директоры Эрик Шмидт енгізді. Бүгінгі күні бүкіл Netflix, TikTok, Instagram бұлт үстінде жұмыс істейді. 3 ірі провайдер — AWS (Amazon), Azure (Microsoft), Google Cloud — әлем нарығының 65% иелейді. Cloud computing means storing and processing data on remote data-centres rather than your own laptop, via the Internet. The term was coined in 2006 by Eric Schmidt, then CEO of Google. Today, Netflix, TikTok, Instagram all run on the cloud. Three giants — AWS (Amazon), Azure (Microsoft), Google Cloud — own 65% of the market. Облачные вычисления — хранение и обработка данных не на твоём ноутбуке, а в удалённых дата-центрах через Интернет. Термин ввёл в 2006 г. Эрик Шмидт, глава Google. Сегодня Netflix, TikTok, Instagram работают в облаке. 3 гиганта — AWS (Amazon), Azure (Microsoft), Google Cloud — держат 65% мирового рынка.
