Data types in Excel

Типы данных в Excel

Неге тип маңызды? Why do types matter? Почему тип важен?

Ұяшыққа сан немесе мәтін жазғаныңда, Excel оны «сезіп», өзі тип анықтайды. Әр тип үшін жеке ережелер қолданылады: сандарды қосуға, күндерді шегеруге, мәтінді біріктіруге болады. Егер тип дұрыс емес болса — формула істемейді, графиктер бұзылады, «жоғалған» нөлдер пайда болады. Сондықтан «сан — санмен, мәтін — мәтінмен» дегенді есте сақтау керек. When you type into a cell, Excel senses the data and auto-detects its type. Each type has its own rules: numbers can be added, dates subtracted, text concatenated. Wrong type = formulas won't work, charts break, leading zeros disappear. Remember: «number with number, text with text». Когда ты что-то пишешь в ячейку, Excel определяет тип сам. У каждого типа — свои правила: числа складываются, даты вычитаются, тексты склеиваются. Неверный тип → формула не работает, графики кривые, ведущие нули теряются. Запомни: «число с числом, текст с текстом».

Сан (Number)NumberЧисло

бүтін, бөлшек, теріс, %int, float, negative, %целое, дробное, отриц., %

Ұяшықта оңға тураланады. 15 таңбалық дәлдік. Мысал: 42, −3,14, 1,5E+06, 85%. Aligned right by default. 15-digit precision. e.g. 42, −3.14, 1.5E+06, 85%. Выравнивается по правому краю. Точность — 15 знаков. Напр.: 42, −3,14, 1,5E+06, 85%.

Бөлшек бөлгіш: үтір (,) орыс тілінде, нүкте (.) ағылшынша.Decimal: comma (,) in RU, dot (.) in EN.Разделитель: запятая (,) в RU, точка (.) в EN.

Мәтін (Text)TextТекст

32 767 таңбаға дейінup to 32 767 charsдо 32 767 символов

Ұяшықта солға тураланады. Кез келген таңба: әріп, сан, эмодзи. Мысал: «Aidar», «007», «8 (700) 123» Aligned left. Any chars — letters, digits, emoji. e.g. «Aidar», «007», «+7 700 123». Выравнивается по левому. Любые символы: буквы, цифры, эмодзи. Напр.: «Aidar», «007», «+7 700 123».

💡 Ұяшықта «007» сақтау үшін: алдын-ала Format→Text немесе алдыға апостроф '007.To keep «007»: Format → Text, or prefix with '007.Чтобы сохранить «007»: Format → Text, или префикс '007.

Күн/УақытDate/TimeДата/Время

1900-01-01-ден — күндер саныdays since 1900-01-01дни от 1900-01-01

Сан түрінде сақталады: 2024-01-15 = 45 306. Уақыт — тәуліктің бөлшегі: 12:00 = 0,5. Сондықтан күндерді шегеруге, қосуға болады. Stored as a number: 2024-01-15 = 45 306. Time is fraction of a day: 12:00 = 0.5. So you can subtract or add dates. Хранится как число: 2024-01-15 = 45 306. Время — доля суток: 12:00 = 0,5. Поэтому даты можно вычитать и складывать.

Логикалық (Boolean)BooleanЛогический

TRUE / FALSE

Тек 2 мән. Ұяшықта ортаға, бас әріппен. Салыстыру формулаларынан автоматты пайда болады: =A1>B1. Only 2 values. Centered, UPPERCASE. Appears from compare formulas: =A1>B1. Только 2 значения. По центру, ЗАГЛАВНЫМИ. Получается из сравнений: =A1>B1.

🟢 Formula (формулаformulaформула)

«=» белгісімен басталады. Ұяшықта формула тұрады, бірақ нәтижесі көрінеді. Starts with «=». Cell holds formula, shows the result. Начинается с «=». В ячейке — формула, видно результат.

=A1+B1
=SUM(A1:A10)

⚠️ Жиі кездесетін қателіктер ⚠️ Common pitfalls ⚠️ Частые ловушки

  • ❌ «12,5» (үтір) vs «12.5» (нүкте) — тілдік параметр әртүрлі, біреуі мәтін болып қалуы мүмкін. «12.5» vs «12,5» — depends on locale; one may become text. «12,5» vs «12.5» — зависит от языка системы; одно может стать текстом.
  • ❌ «007» енгізсең — нөл жоғалады. Format → Text алдымен. Typing «007» loses leading zero. Set Text format first. «007» превратится в 7. Сначала Format → Text.
  • ❌ Күнді «15.01.24» деп жазсаң — Excel 2024 деп түсінбейді. Толық формат: «15.01.2024». Date «15.01.24» may misinterpret century. Use full year. Дата «15.01.24» может быть понята как 1924. Пиши полный год.
  • ❌ Сан мен бос орын: «1 000» — бос орын мәтінге айналдырады. Format → Number ерекше бөлгіш береді. Space in «1 000» may turn it into text. Use Number format instead. Пробел в «1 000» делает его текстом. Используй формат Number.
  • ❌ Мәтіндегі сандарды қоссаң SUM = 0. Алдымен VALUE-мен санға түрлендір. SUM of text numbers returns 0. Convert with VALUE first. SUM над «текстовыми» числами даёт 0. Сначала VALUE.
