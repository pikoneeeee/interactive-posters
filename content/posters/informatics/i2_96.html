БД дегеніміз не? What is a database? Что такое БД?

Деректер қоры (БД, database) — ұйымдасқан, тез іздеуге ыңғайлы сақталған мәліметтер жиынтығы. Бірінші реляциялық модельді Эдгар Кодд 1970 жылы ұсынды. Бүгінде дүниежүзінде 170+ зеттабайт дерек сақталады. Ең танымал БД: MySQL, PostgreSQL, Oracle, SQLite, Microsoft SQL, MongoDB. Қарапайым БД Excel кестесіне ұқсайды — өрістер (баған) мен жазбалар (жол). A database is an organised collection of data that is easy to search. Edgar Codd invented the relational model in 1970. Today the world holds 170+ zettabytes of data. Popular DBs: MySQL, PostgreSQL, Oracle, SQLite, MS SQL, MongoDB. A simple DB looks like an Excel sheet — fields (columns) and records (rows). База данных (БД) — организованный, удобный для поиска набор данных. Реляционную модель изобрёл Эдгар Кодд в 1970 г. Сегодня в мире хранится 170+ зеттабайт данных. Популярные СУБД: MySQL, PostgreSQL, Oracle, SQLite, MS SQL, MongoDB. Простая БД похожа на Excel-таблицу — поля (колонки) и записи (строки).
