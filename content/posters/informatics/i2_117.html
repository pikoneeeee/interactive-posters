Encryption & backups

Шифрование и резервные копии

🔐 Шифрлеу — не? 🔐 What is encryption? 🔐 Что такое шифрование?

Шифрлеу — деректі кілтпен түсініксіз сандарға айналдыру. Нәтижесінде оны тек кілтті білетін адам кері оқи алады. Ең ежелгі шифр — Цезарь шифры (б.з.д. 50 ж.), бүгінгі стандарт — AES-256. Интернет арқылы HTTPS жібергенде әр байт шифрланады. Резервтік көшірме (backup) — деректің 2-ші көшірмесі, дискі істен шығып қалса немесе ransomware шабуыл болса — құтқарады. Екеуі бірге — сенің маңызды файлдарыңды сақтайды. Encryption turns data into unreadable bytes using a key. Only someone with the key can reverse it. The oldest cipher is Caesar's (50 BC); today's standard is AES-256. Every HTTPS byte online is encrypted. A backup is a second copy — saves you when a disk dies or ransomware strikes. Together they protect your important files. Шифрование превращает данные в нечитаемые байты с помощью ключа. Только знающий ключ может их прочитать. Самый древний шифр — Цезаря (50 г. до н.э.); сегодня стандарт — AES-256. Каждый байт HTTPS шифруется. Резервная копия (backup) — второй экземпляр данных, спасает при сбое диска или ransomware. Вместе они защищают твои важные файлы.

#️⃣ Хеш — «қолтаңба» #️⃣ Hash — a fingerprint #️⃣ Хеш — «отпечаток»

Хеш-функция — кез келген деректі тұрақты ұзындықтағы қысқа жолға айналдырады. Бір бит өзгерсе — хеш толық өзгеріп кетеді. Бұл шифрлеу емес: хештен түпнұсқаны қалпына келтіру мүмкін емес. A hash function turns any data into a fixed-length short string. Change one bit — the hash changes completely. This is not encryption: you cannot recover the original from a hash. Хеш-функция превращает любые данные в короткую строку фиксированной длины. Меняется 1 бит — хеш меняется целиком. Это не шифрование: восстановить исходник из хеша нельзя.
