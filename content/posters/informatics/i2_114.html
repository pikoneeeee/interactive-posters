IP address and DNS

IP-адрес и DNS

🌐 Интернеттің «пошта индексі» 🌐 Internet's postal code 🌐 «Почтовый индекс» интернета

IP-мекенжай (Internet Protocol address) — желідегі әр құрылғының бірегей нөмірі. Ол пакеттің қайдан келгенін және қайда кететінін көрсетеді. DNS (Domain Name System) — интернеттің телефон кітапшасы: google.com сияқты атауларды IP-нөмірлерге аударады. DNS-ті 1983 жылы Пол Мокапетрис ойлап тапты: оған дейін барлық компьютерлер бір hosts.txt файлын алмасатын! Бүгін DNS күніне трлн сауал өңдейді. An IP address (Internet Protocol) is a unique number for every networked device — it tells where a packet comes from and where it goes. DNS (Domain Name System) is the internet's phone book: it translates names like google.com into IPs. DNS was invented by Paul Mockapetris in 1983; before that every computer downloaded a single hosts.txt! Today DNS handles trillions of queries per day. IP-адрес (Internet Protocol) — уникальный номер устройства в сети. Он сообщает, откуда и куда идёт пакет. DNS (Domain Name System) — телефонная книга интернета: переводит имена вроде google.com в IP. DNS придумал Пол Мокапетрис в 1983 г. До этого все компьютеры скачивали один файл hosts.txt! Сегодня DNS обрабатывает трлн запросов в сутки.

📖 DNS қалай жұмыс істейді? 📖 How DNS works 📖 Как работает DNS

  1. 1. Браузер: google.com атауын сұрайды.Browser asks for google.com.Браузер запрашивает google.com.
  2. 2. ISP resolver кэшінен қарайды.ISP resolver checks its cache.ISP-резолвер смотрит в кэш.
  3. 3. Жоқ болса — root (13 сервер) → .com TLD → authoritative NS тізбегімен іздейді.If miss — asks root (13 servers) → .com TLD → authoritative NS.Если нет — спрашивает root (13 серверов) → .com TLD → authoritative NS.
  4. 4. IP-ді кэштеп, PC-ге қайтарады.Caches the IP, returns to PC.Кэширует IP и возвращает ПК.

⏱ Жалпы уақыт: ~20-50 мс (кэштен — 1-2 мс). ⏱ Total: ~20-50 ms; from cache: 1-2 ms. ⏱ Общее время: ~20-50 мс; из кэша — 1-2 мс.
