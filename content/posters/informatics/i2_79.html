Цикл while

Цикл не үшін керек? Why loops? Зачем нужны циклы?

Цикл — «орындау + қайталау + қайталау + ...». Бізге 1000 рет print("Hello") жазу керек пе? Жоқ! Циклмен — 3 жолда. while латын тілінде «пока», «әзірше». Орындалу реті: шарт тексеріледі → True-да тәне орындалады → шартқа қайта оралады. Шарт False болғанда цикл тоқтайды. Мектепке келген бірінші цикл 1950 жылы ALGOL-да пайда болды. Бүгінге дейін әр бағдарламашы күнде қолданады! A loop is «execute + repeat + repeat…». Need print("Hello") 1 000 times? Not by hand — a loop does it in 3 lines. while means «as long as». Flow: check condition → if True, run body → back to check. Stops when condition is False. The first loop appeared in ALGOL in 1950 and is used daily by every programmer. Цикл — «выполни + повтори + повтори…». Нужно написать print("Hello") 1 000 раз? Не вручную — цикл сделает это в 3 строки. while = «пока». Порядок: проверка условия → если True, выполнить тело → вернуться к проверке. Останавливается при False. Первый цикл появился в ALGOL в 1950 году.

♾ Шексіз цикл — қауіп! ♾ Infinite loop — danger! ♾ Бесконечный цикл — опасность!

Шартты қойып, оны ешқашан өзгертпесең — цикл мәңгі орындалады. Программа жай болып, тоқтатуға Ctrl+C қажет. If the condition never changes, the loop runs forever. Press Ctrl+C to stop. Если условие никогда не меняется, цикл работает вечно. Останови клавишами Ctrl+C.

# ❌ мәңгі жұмыс!forever!бесконечно! i = 1 while i < 10: print(i) # i += 1 ұмытылды!
# ✅ дұрысcorrectправильно i = 1 while i < 10: print(i) i += 1 # ← қадамstepшаг
