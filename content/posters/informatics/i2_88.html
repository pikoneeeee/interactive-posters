«Debug» сөзі қайдан келді? Where does «debug» come from? Откуда слово «debug»?

1947 жылы Гарвардтың «Mark II» компьютерінде инженер Грейс Хоппер нақты моль (insect — bug) тапты — ол релені қысып қалған еді. Оны журналға жапсырып: «First actual case of bug being found» деп жазды. Содан бері барлық қате — «bug», қатені жою — «debug». In 1947 engineer Grace Hopper found a real moth jammed in a relay of Harvard's «Mark II». She taped it into the log: «First actual case of bug being found». Since then every error is a «bug» and fixing it is «debug». В 1947 году инженер Грейс Хоппер нашла в реле компьютера «Mark II» реального мотылька (bug). Приклеила его в журнал: «First actual case of bug being found». С тех пор ошибка — «bug», а её поиск — «debug».

🎯 Мысал — санау қате шығарды 🎯 Example — buggy sum 🎯 Пример — баг в сумме

❌ Қате кодBuggyС ошибкой:

def sum_even(nums): s = 0 for x in nums: if x % 2: # ← ?? s += x return s print(sum_even([1,2,3,4])) # → 4, but expected 6

✅ ТүзетілдіFixedИсправлено:

if x % 2 == 0: # жұп — қалдық 0even = remainder 0чётное — остаток 0 s += x

💡 «if x % 2» → x тақ болса ғана шын (Python-да 1 = True). Қатені табу үшін print(x, s) қоссаң болды. 💡 «if x % 2» is True for odd numbers (1 is truthy). Adding print(x,s) reveals it in 5 seconds. 💡 «if x % 2» — истинно для нечётных (1 = True). print(x, s) показывает ошибку за 5 сек.

🦆 «Резеңке үйрек» әдісі 🦆 Rubber-duck debugging 🦆 Метод «резиновой утки»

🦆

Кодты резеңке үйрекке сөйлеп түсіндір — «міне осы жол a-ны … жасайды». 90% жағдайда қатені өзің табасың! Бұл әдіс 1999 жылы «Pragmatic Programmer» кітабында жарияланды. Үйрек жоқ болса — кез келген затпен (саусақ, мысық, жансыз фигура) сөйлес. Explain your code out loud to a rubber duck — «this line takes a and …». In 90% of cases you find the bug yourself. Popularised by «The Pragmatic Programmer» (1999). No duck? Talk to your cat, pencil or the ceiling. Объясни код резиновой утке вслух: «вот эта строка берёт a и …». В 90% случаев баг находишь сам! Описано в книге «The Pragmatic Programmer» (1999). Нет утки — говори с котом, карандашом, потолком.
