Антивирусная безопасность

Антивирус дегеніміз не? What is an antivirus? Что такое антивирус?

Антивирус — компьютердің қорғаушы бағдарламасы: зиянды файлдарды іздейді, жояды және жаңа инфекциялардан сақтайды. Ол компьютер үшін иммундық жүйе сияқты: жадыны үздіксіз сканерлеп, әр файлды «таныс вирус» базасымен салыстырады. Егер сәйкестік табылса — файл карантинге салынады (қауіпсіз қорапша), содан кейін жойылады. An antivirus is a protection program that finds, removes malicious files and prevents new infections. It is an immune system for your PC: it constantly scans memory and checks every file against a «known virus» database. On match the file is moved to quarantine (a safe sandbox) and then deleted. Антивирус — защитная программа компьютера: ищет вредные файлы, удаляет их и не даёт заражать заново. Он как иммунная система: постоянно сканирует память и сравнивает каждый файл с базой «знакомых вирусов». Если совпало — файл отправляется в карантин (безопасный ящик) и удаляется.

🧪 Тесттен өту — EICAR 🧪 Testing — EICAR file 🧪 Проверка — файл EICAR

Антивирусыңның жұмыс істеп жатқанын білгің келсе — EICAR Test File жүкте (www.eicar.org). Бұл зиянсыз жол, бірақ барлық антивирустар оны «вирус» ретінде ұстайды. Егер ұстамаса — сенің қорғанысың жұмыс істемей тұр! Want to know if your antivirus works? Download the EICAR Test File (www.eicar.org). It is a harmless string, but every antivirus detects it as a virus. If yours doesn't — it is broken! Хочешь узнать, работает ли антивирус? Скачай тест-файл EICAR (www.eicar.org). Это безопасная строка, но её ловят ВСЕ антивирусы. Не поймал — значит не работает!

X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*
