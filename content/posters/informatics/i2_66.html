Python-да файлды оқу мен жазу

Reading and writing files in Python

Чтение и запись файлов в Python

Неге файл керек? Why files? Зачем нужны файлы?

Бағдарламаны тоқтатсаң — айнымалылардағы бәрі жойылады. Деректерді сақтауға керек — сол үшін файл қолданылады. Python-да файлдармен жұмыс істеу 3 қадамнан тұрады: (1) ашу (open), (2) оқу / жазу (read / write), (3) жабу (close). Дұрыс тәжірибе: with блогы — файл автоматты жабылады. Файлдар арқылы бағдарлама күнделіктер жүргізеді, ойын кескінін сақтайды, CSV және JSON деректерін өңдейді. When a program stops, all variables vanish. To persist data we use files. In Python file work has 3 steps: (1) open, (2) read / write, (3) close. Best practice: the with block auto-closes the file. Files let programs keep logs, save game progress, process CSV and JSON. Когда программа завершается, все переменные пропадают. Чтобы данные остались, используют файлы. В Python работа с файлом = 3 шага: (1) открыть (open), (2) читать / писать, (3) закрыть (close). Хорошая практика — блок with, который сам закрывает файл. Через файлы программы ведут журналы, сохраняют игру, обрабатывают CSV и JSON.

📖 Оқу әдістері 📖 Reading methods 📖 Способы чтения

1. Барлық файлдыWhole fileВесь файл

with open("data.txt", "r", encoding="utf-8") as f: text = f.read() print(text)

2. Жол-жолдап (оңтайлы)Line by lineПострочно

with open("data.txt", encoding="utf-8") as f: for line in f: print(line.strip())

3. Барлық жолды тізім ретіндеAll lines as listВсе строки в список

with open("data.txt") as f: lines = f.readlines() print(len(lines), "lines")

4. Бір жол оқуRead one lineОдну строку

with open("data.txt") as f: first = f.readline() second = f.readline()

✍️ Жазу әдістері ✍️ Writing methods ✍️ Способы записи

1. write() — ескіні жоядыoverwriteперезапись

with open("out.txt", "w", encoding="utf-8") as f: f.write("Hello!\n") f.write("Сәлем!\n")

2. "a" — append

with open("log.txt", "a") as f: f.write(f"[log] {event}\n") # ескі мазмұн қаладыold content staysстарое остаётся

3. writelines() — тізімненfrom listиз списка

items = ["apple\n", "banana\n", "pear\n"] with open("fruits.txt", "w") as f: f.writelines(items)

4. print-пен жазу

with open("out.txt", "w") as f: print("Hello", 42, file=f) # \n автоматты қосыладыauto newlineпереход строки сам

✨ with блогы — алтын ереже ✨ «with» block — the golden rule ✨ Блок «with» — золотое правило

with блогы файлды автоматты жабады — тіпті қате шығарса да. Бұл ескі f.close() шақырудан ыңғайлы әрі қауіпсіз. with auto-closes the file even on errors. Safer and tidier than manual f.close(). with сам закрывает файл, даже если случилась ошибка. Безопаснее и короче, чем ручной f.close().

with open("data.txt") as f: text = f.read() # автоматты жабыладыauto closesзакроется сам
