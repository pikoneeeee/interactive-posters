500+ функция — не үшін? 500+ functions — why? 500+ функций — зачем?

Excel-де 500-ден астам дайын функция бар. Олар санау, мәтінмен жұмыс, күн, логика, іздеу — барлық есептерді бірнеше таңба арқылы шешуге мүмкіндік береді. Мысалы, =SUM(A1:A100) — 100 ұяшықтың қосындысын 1 секундта береді. Функция 3 бөліктен тұрады: аты (SUM), жақшалар ( ), аргументтер (жақша ішіндегі деректер). Функция ағылшынша жазылады — орысша Excel-де де SUM емес, СУММ. Әлемдегі «де-факто» стандарт үшін ағылшынша нұсқасын үйренген жақсы! Excel has 500+ built-in functions. They let you count, manipulate text, work with dates, logic, lookups — any task solved in a few characters. Example: =SUM(A1:A100) sums 100 cells in 1 second. A function has 3 parts: name (SUM), parentheses, arguments. Function names are usually in English — that's the world standard! В Excel более 500 встроенных функций. Они позволяют считать, работать с текстом, датами, логикой, поиском — всё решается несколькими символами. Пример: =SUM(A1:A100) — сумма 100 ячеек за 1 секунду. Функция состоит из 3 частей: имя, скобки, аргументы. Имена часто на английском — это мировой стандарт!

=ФУНКЦИЯ(аргумент1, аргумент2, ...)
