Arithmetic expressions in Python

Арифметические выражения в Python

Python — қолыңыздағы калькулятор Python as your calculator Python — твой калькулятор

Python кез келген математикалық есептеуді оп-оңай шығарады. Сенің қалыпты калькулятордан айырмашылығы — ол айнымалылармен істейді, нәтижені сақтап қояды және миллиардтаған есептерді секундына орындайды. 7 арифметикалық оператор бар: 4-еуі мектептегі сияқты (+, −, ×, ÷) және 3 «экстра»: бүтіндік бөлу (//), қалдық (%), дәреже (**). Осы операторлар мен жақшалар математикадағыдай ретпен есептеледі — PEMDAS ережесі бойынша. Python solves any maths problem in a flash. Unlike a plain calculator it works with variables, remembers results and crunches billions of operations per second. It has 7 arithmetic operators: 4 usual ones (+, −, ×, ÷) and 3 extras — integer division (//), remainder (%) and power (**). They follow the same order of operations you learn at school — PEMDAS. Python решает любую задачу за долю секунды. В отличие от обычного калькулятора он работает с переменными, запоминает результаты и делает миллиарды операций в секунду. Есть 7 арифметических операторов: 4 школьных (+, −, ×, ÷) и 3 дополнительных — целочисленное деление (//), остаток (%) и возведение в степень (**). Они подчиняются обычному порядку действий — PEMDAS.
