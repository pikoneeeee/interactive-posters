🧠 ML — не? 🧠 What is ML? 🧠 Что такое ML?

Машиналық оқыту (ML) — ережелерді қолмен жазудың орнына, компьютер мысалдардан өзі үйренетін тәсіл. Термин 1959 ж. Arthur Samuel (IBM) кіргізді — ол 200 млн шашка партиясында өз-өзін жаттықтыратын бағдарлама жазды! Формула: деректер + алгоритм → модель → болжам. Қазіргі 80% AI жетістігі — ML арқылы. Machine Learning (ML) is a paradigm where, instead of writing rules by hand, the computer learns from examples. The term was coined by Arthur Samuel (IBM, 1959) — he built a checkers program that trained itself on 200 M games! Formula: data + algorithm → model → predictions. Today ~80% of AI advances come from ML. Машинное обучение (ML) — подход, при котором компьютер учится по примерам, а не получает правила от программиста. Термин ввёл Артур Самуэль (IBM, 1959) — его программа игры в шашки самообучалась на 200 млн партий! Формула: данные + алгоритм → модель → предсказания. Сегодня ~80% успехов AI — именно ML.

🐍 Python + scikit-learn мысалы 🐍 Python + scikit-learn example 🐍 Пример на Python + scikit-learn

from sklearn.datasets import load_iris from sklearn.model_selection import train_test_split from sklearn.tree import DecisionTreeClassifier from sklearn.metrics import accuracy_score # 1. Данные: 150 ирисов × 4 признака X, y = load_iris(return_X_y=True) # 2. Train / test X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2) # 3. Обучение model = DecisionTreeClassifier() model.fit(X_tr, y_tr) # 4. Предсказание + точность pred = model.predict(X_te) print(accuracy_score(y_te, pred)) # ≈ 0.97
