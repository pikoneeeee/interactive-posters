Массив — не? What is an array? Что такое массив?

Массив — бір түрлі деректердің реттелген жиынтығы. Әр элементтің өз индексі (нөмірі) бар. Python-да ол list деп аталады. Массивтер 1957 жылы FORTRAN тілінде пайда болды. Олар — жадыдағы қатар орналасқан жәшіктер тізбегі. Массивсіз ешбір ойын, музыка, суретке келмейсің: RGB пикселдер — 3 элементті массив, .wav — миллиондаған сан, JSON API — массив-объект-массив! An array is an ordered collection of same-type values. Each element has an index. In Python it's a list. Arrays were introduced in FORTRAN (1957). Physically it's a row of adjacent cells in memory. Everything uses arrays: RGB pixel = 3-element array, a .wav file = millions of samples, a JSON API = array of objects. Массив — упорядоченный набор однотипных данных; у каждого элемента есть индекс. В Python его зовут list. Массивы появились в FORTRAN (1957). В памяти — это соседние ячейки. Они всюду: RGB-пиксель = массив из 3 чисел, .wav-файл = миллионы отсчётов, JSON-API = массив объектов!
