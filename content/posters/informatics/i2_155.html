Шифрование: математика тайны

🔐 Шифрлау — не? 🔐 What is encryption? 🔐 Что такое шифрование?

Шифрлау — ашық мәтінді (plaintext) кілт арқылы түсініксіз шифртекстке айналдыру, кейін сол кілтпен ғана қайта ашу. Тарих: Цезарь шифры (б.з.д. 50 ж., 3 әріпке ығыстыру), Enigma (1940) — бұзылды, AES (2001) — бүгінгі стандарт, RSA (1977) — ашық кілт революциясы. Бүгін HTTPS, банк, WhatsApp, Bitcoin — бәрі шифрлауға сүйенеді. Ереже: «қауіпсіздік алгоритмнің құпия екенінен емес, кілтке сенімді болуынан» (Керкгоффс принципі). Encryption turns plaintext into unreadable ciphertext using a key; only the key can decrypt it back. History: Caesar cipher (50 BC, shift by 3), Enigma (1940) — cracked, AES (2001) — today's standard, RSA (1977) — public-key revolution. Today HTTPS, banks, WhatsApp, Bitcoin all rely on encryption. Rule: «security must rely on the key, not on keeping the algorithm secret» (Kerckhoffs' principle). Шифрование превращает открытый текст (plaintext) в шифртекст с помощью ключа; расшифровать можно только этим же ключом. История: шифр Цезаря (50 до н. э., сдвиг на 3), Enigma (1940) — взломана, AES (2001) — современный стандарт, RSA (1977) — революция открытого ключа. Сегодня HTTPS, банки, WhatsApp, Bitcoin — всё на шифровании. Правило: «стойкость — в ключе, не в тайне алгоритма» (принцип Керкгоффса).

📜 Цезарь шифры (мысал) 📜 Caesar cipher (example) 📜 Шифр Цезаря (пример)

def caesar(text, key=3): out = "" for ch in text.upper(): if ch.isalpha(): out += chr((ord(ch) - ord('A') + key) % 26 + ord('A')) else: out += ch return out print(caesar("HELLO", 3)) # KHOOR print(caesar("KHOOR", -3)) # HELLO

⚠ Бар болғаны 26 кілт — компьютер секундта бұзады. Тек оқу үшін! ⚠ Only 26 keys — a computer cracks it in a second. Educational only! ⚠ Всего 26 ключей — комп взломает за секунду. Только для учёбы!

🔑🔑 Асимметриялық шифр 🔑🔑 Asymmetric cipher 🔑🔑 Асимметричное шифрование

2 кілт: public (бәріне таратуға болады) — шифрлайды, private (тек иесінде) — ашады. Ашық кілтті интернетте жариялауға болады — бұл революция! Two keys: public (share freely) encrypts, private (kept secret) decrypts. You can post the public key anywhere — this was the revolution! Два ключа: публичный (можно раздавать всем) — шифрует, приватный (только у владельца) — расшифровывает. Открытый ключ можно публиковать — это и есть революция!

#️⃣ Хеш + қолтаңба #️⃣ Hash + signature #️⃣ Хеш + подпись

Хеш — кез келген өлшемдегі деректен бекітілген ұзындықтағы «саусақ ізін» жасайтын біржақты функция. Кері қайтарылмайды! Сенімге, тұтастыққа қолданылады. A hash maps any data to a fixed-size fingerprint, one-way (no reverse). Used for integrity & signatures. Хеш превращает любые данные в «отпечаток» фиксированной длины. Необратим! Для целостности и подписей.
