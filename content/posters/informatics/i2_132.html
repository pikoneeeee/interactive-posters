📜 SQL — не? 📜 What is SQL? 📜 Что такое SQL?

SQL (Structured Query Language) — декларативті дерекқор тілі. 1974 ж. IBM (Donald Chamberlin, Raymond Boyce) ойлап тапты. Сен айтасың «не керек», ал қалай табу — дерекқордың өз жұмысы! SQL 4 үлкен бөлімнен тұрады: DDL (CREATE, DROP), DML (INSERT, UPDATE, DELETE), DQL (SELECT), DCL (GRANT). Барлық қатынас жасау тілдеріндегі (Python, Java, PHP) БД-мен сөйлесу — SQL арқылы. SQL (Structured Query Language) is a declarative database language, invented at IBM in 1974 by Donald Chamberlin & Raymond Boyce. You say WHAT you want, the DB figures out HOW. SQL has 4 main parts: DDL (CREATE, DROP), DML (INSERT, UPDATE, DELETE), DQL (SELECT), DCL (GRANT). Every app language (Python, Java, PHP) talks to DBs via SQL. SQL (Structured Query Language) — декларативный язык для работы с БД. Придуман в IBM в 1974 г. Дональдом Чемберлином и Рэймондом Бойсом. Ты пишешь «что нужно», а БД сама решает «как найти»! SQL делится на 4 группы: DDL (CREATE, DROP), DML (INSERT, UPDATE, DELETE), DQL (SELECT), DCL (GRANT). Любой язык (Python, Java, PHP) общается с БД через SQL.

🏗 CREATE TABLE — кесте құру 🏗 CREATE TABLE — building a table 🏗 CREATE TABLE — создание таблицы

CREATE TABLE students ( id INTEGER PRIMARY KEY AUTOINCREMENT, name VARCHAR(100) NOT NULL, grade INTEGER CHECK (grade BETWEEN 1 AND 11), email VARCHAR(80) UNIQUE, birthdate DATE, active BOOLEAN DEFAULT 1, class_id INTEGER, FOREIGN KEY (class_id) REFERENCES classes(id) );

📥 INSERT — деректерді қосу 📥 INSERT — adding rows 📥 INSERT — добавление данных

-- 1. Явно указать столбцы (рекомендуется!) INSERT INTO students (name, grade, email) VALUES ('Aida', 10, 'aida@school.kz'); -- 2. Все столбцы по порядку INSERT INTO students VALUES (2, 'Nurlan', 10, 'nur@school.kz', '2009-07-22', 1, 25); -- 3. Несколько строк разом (batch) INSERT INTO students (name, grade) VALUES ('Dilnaz', 9), ('Arman', 10), ('Bota', 11); -- 4. Вставить из другой таблицы INSERT INTO archive (name, grade) SELECT name, grade FROM students WHERE grade = 11;

✏ UPDATE & DELETE ✏ UPDATE & DELETE ✏ UPDATE и DELETE

-- UPDATE — изменить значения UPDATE students SET grade = 11, email = 'aida11@school.kz' WHERE id = 1; -- ОБЯЗАТЕЛЬНО WHERE! иначе поменяется ВСЁ -- DELETE — удалить строки DELETE FROM students WHERE active = 0; -- очистить всю таблицу, оставив структуру TRUNCATE TABLE students; -- удалить таблицу целиком DROP TABLE students;

⚠ WHERE ұмытсаң — бүкіл кесте өзгереді/жойылады! Әрқашан алдымен SELECT-пен тексер! ⚠ Forget WHERE and the whole table changes/dies! Always run SELECT first to verify! ⚠ Забыл WHERE — изменится/удалится ВСЯ таблица! Всегда проверяй сначала SELECT-ом!

Н. Иванова'), (2, '10Б', 'Е. С. Сагиева'); INSERT INTO students (name, class_id) VALUES ('Aida', 1), ('Nurlan', 1), ('Dilnaz', 2), ('Arman', 1); UPDATE students SET class_id = 2 WHERE name = 'Arman'; DELETE FROM students WHERE name = 'Nurlan';
