🌐 HTML — не? 🌐 What is HTML? 🌐 Что такое HTML?

HTML (HyperText Markup Language) — бет құрылымын сипаттайтын белгілеу тілі. Оны 1991 жылы Tim Berners-Lee (CERN) ойлап тапты, Web-тің туылуы осыдан басталды. Бет — элементтерден (tag) тұрады: <h1>, <p>, <img>. HTML — бағдарламалау тілі емес, ол мәтінді «осы тақырып, осы сурет, осы сілтеме» деп белгілейді. Көрініс — CSS-пен, мінез-құлық — JS-пен. HTML (HyperText Markup Language) is a markup language that describes a page's structure. Invented by Tim Berners-Lee at CERN in 1991 — the birth of the Web. A page is made of elements (tags): <h1>, <p>, <img>. HTML is not a programming language — it simply marks text as «a heading, an image, a link». Styling is done with CSS, behaviour with JS. HTML (HyperText Markup Language) — язык разметки, описывающий структуру страницы. Придуман Тимом Бернерсом-Ли (ЦЕРН, 1991 г.), с него начался Веб. Страница состоит из элементов (тегов): <h1>, <p>, <img>. HTML — не язык программирования; он лишь говорит: «это заголовок, это картинка, это ссылка». Внешний вид — через CSS, поведение — через JS.

🏛 Семантикалық разметка (HTML5) 🏛 Semantic layout (HTML5) 🏛 Семантическая разметка (HTML5)

HTML5-те div-супті орнына мағыналы тегтер қолданамыз — экранды оқушыларға, іздеу жүйесіне, сенімді. HTML5 replaces «div soup» with semantic tags — better for screen readers and search engines. В HTML5 вместо «супа из div» используем семантические теги — удобнее для скринридеров и поисковиков.

<body> <header>...</header> <nav>...</nav> <main> <article> <h2>Новость</h2> <p>...</p> </article> <section>...</section> </main> <aside>...</aside> <footer>© 2025 School</footer> </body>

🏷 Атрибуттар 🏷 Attributes 🏷 Атрибуты

Атрибут — тегке қосымша ақпарат береді: атау="мәні". An attribute adds extra info to a tag: name="value". Атрибут добавляет тегу дополнительную информацию: имя="значение".

<a href="https://kaspi.kz" target="_blank" title="Открыть">Каспи</a> <img src="photo.png" alt="Фото школы" width="300"> <input type="password" placeholder="Пароль" required> <div class="card hero" id="intro" data-user="42">...</div>
