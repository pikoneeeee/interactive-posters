Supervised vs Unsupervised

Supervised vs Unsupervised

Обучение с учителем и без учителя

📚 ML-дің 3 парадигмасы 📚 3 ML paradigms 📚 3 парадигмы ML

Машиналық оқыту үш негізгі сызбаға бөлінеді. Оларды оқушы мен оқулық мысалымен түсіну оңай: 1) Supervised — жауаптары белгілі тапсырмалармен оқу («мына сурет — мысық»). 2) Unsupervised — жауабы жоқ мысалдарды топтарға бөлу («ұқсастарды тап»). 3) Reinforcement — әрекет ету арқылы марапат пен жаза қабылдау. Machine learning has three main paradigms, easy to picture with a student metaphor. 1) Supervised — learn from labeled answers («this picture is a cat»). 2) Unsupervised — no labels; find groups by yourself. 3) Reinforcement — act in an environment, receive reward/penalty. Машинное обучение делится на три основные парадигмы. Легко понять через школьную аналогию: 1) С учителем — учимся на задачах с известными ответами («эта картинка — кошка»). 2) Без учителя — ответов нет, сами ищем группы. 3) С подкреплением — действуем в среде и получаем награду или штраф.

👩‍🏫 Supervised — ұстазбен 👩‍🏫 Supervised — with a teacher 👩‍🏫 С учителем

Модельге (x → y) жұптары беріледі. Мақсаты — f(x) = y функциясын табу. The model receives (x → y) pairs. Goal: learn the mapping f(x) = y. Модель получает пары (x → y). Цель — найти функцию f(x) = y.

🔍 Unsupervised — ұстазсыз 🔍 Unsupervised — no labels 🔍 Без учителя

Тек x берілген, y жоқ. Модель деректердің жасырын құрылымын табады. Only x, no y. The model discovers hidden structure in data. Есть только x, y отсутствует. Модель сама ищет скрытую структуру.
