CIA-үштігі

CIA triad

CIA-триада

🛡 Қауіпсіздіктің 3 тірегі 🛡 3 pillars of security 🛡 3 столпа безопасности

CIA-үштігі — ақпараттық қауіпсіздіктегі ең іргелі ереже. Оған барлау агенттігі (CIA) емес, 3 қасиеттің бірінші әріптері жатады: Confidentiality (құпиялық), Integrity (тұтастық), Availability (қолжетімділік). Моделді 1970-ші жылдары АҚШ әскерінде жасады; бүгін бүкіл кибер-қауіпсіздік (банктер, ауруханалар, eGov) осы үштікке сүйенеді. 3 қасиеттің біреуі бұзылса — қауіпсіздік жоқ! The CIA triad is the most fundamental rule in information security — nothing to do with the agency! It stands for Confidentiality, Integrity and Availability. The model was formalised in the 1970s by the US military; today every field of cyber-security — banks, hospitals, eGov — is built on it. If even one pillar is broken, there is no security! CIA-триада — самая фундаментальная модель информационной безопасности (не про разведку!). Это 3 свойства: Confidentiality (конфиденциальность), Integrity (целостность), Availability (доступность). Модель сформировали в 1970-х в армии США; сегодня на ней строят кибербез в банках, больницах, eGov. Сломал один столп — безопасности нет!

⚖️ Үнемі теңгерім ⚖️ Always a balance ⚖️ Всегда баланс

Шамадан тыс C — пайдалануға қиын (тым ұзын пароль, 3 капча). Тым көп A — C зардап шегуі мүмкін (бәріне ашық сайт). Құпиясөзсіз БД — A жоғары, C нөл! Сондықтан қауіпсіздік инженері үнемі үштіктің балансын ойлайды: «бұл өзгеріс C/I/A-ға қалай әсер етеді?». Too much C kills usability (20-char passwords, 3 captchas). Too much A may hurt C (anyone can view). A DB without a password has max A, zero C! A security engineer constantly balances the triad: «how does this change affect C / I / A?». Чрезмерный C — неудобно (20 символов пароля, 3 капчи). Чрезмерный A убивает C (сайт для всех). БД без пароля — максимум A и ноль C! Инженер безопасности всё время балансирует: «как это изменит C / I / A?».
