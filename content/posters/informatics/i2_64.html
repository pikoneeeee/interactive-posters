Кірістірілген шарттар

Nested conditions

Вложенные условия

Кірістіру — не? What is nesting? Что такое вложенность?

Кірістірілген шарт — if-тің ішінде тағы бір if. «Егер... ал оның ішінде егер...». Бұл көп қабатты шешімдерде қолданылады: алдымен бір үлкен сұрақ, содан кейін оның ішіне екінші сұрақ. Күнделікті мысал: «Дүкенге бару керек бе? — Иә, егер ашық болса; ал егер ақша жетсе — шоколад та сатып ал». Кірістіру Python-да шегіністермен белгіленеді: әр жаңа if — +4 бос орын. A nested condition is an if inside another if. «If… and inside if…». It models multi-layered decisions. Example: «Go to the shop? — Yes, if it is open; and if you have money, buy chocolate too». In Python nesting is shown by indents: each new inner if adds +4 spaces. Вложенное условие — это if внутри другого if. «Если… а внутри если…». Описывает многоуровневые решения. Пример: «Идти в магазин? — Да, если открыт; а если есть деньги — купи шоколадку». В Python вложенность показывается отступами: каждый новый if — +4 пробела.
