continue — переход к следующей итерации

continue не істейді? What does continue do? Что делает continue?

continue — «өтіп кет, жалғастыр» дегенді білдіреді. Ол break-тің «ағасы», бірақ цикл тоқтамайды: тек осы итерациядағы қалған кодты өткізіп жіберіп, келесі итерацияға секіреді. Қолданылуы: «кейбір элементтерді елемеу керек» — мысалы, теріс сандарды жіберіп қосынды жасау, бос жолдарды өткізіп кету. break мен continue — циклдердің «жеңіл атыс жүрегі». Екеуі де 1958 жылы FORTRAN-да ойлап табылған. continue means «skip the rest and go on». It is break's cousin but the loop keeps running — only the current iteration's remaining code is skipped, execution jumps to the next iteration. Use it when you want to ignore some elements (skip negatives in a sum, skip blank lines). break & continue are the loop's «steering wheel». Both invented in FORTRAN (1958). continue означает «пропусти и продолжай». Это «брат» break, но цикл не останавливается — пропускается только оставшийся код этой итерации, управление сразу идёт к следующей итерации. Применение: надо пропустить некоторые элементы — например, отрицательные при суммировании, пустые строки в файле. break и continue — «рулевое управление» цикла. Оба появились в FORTRAN в 1958 г.

💡 Тәжірибелік кеңес 💡 Practical tip 💡 Практический совет

«Күрделі if» орнына continue-мен early exit код оқуды жеңілдетеді. Бас идея: «осы итерация маңызды емес бе? — ≥continue. Маңызды — жаса». Early-continue cleans up nested if-statements — «Is this iter irrelevant? → continue. Otherwise do the work». Early-continue делает код чище, чем вложенные if — «Эта итерация не важна? → continue. Иначе работаем».

❌ Терең ұяласуDeep nestingГлубокая вложенность

for u in users: if u.active: if u.age >= 18: if u.email: send(u)

✅ early-continue

for u in users: if not u.active: continue if u.age < 18: continue if not u.email: continue send(u)
