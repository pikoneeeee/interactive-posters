Файловый ввод-вывод в Python

💾 Неге файл керек? 💾 Why files? 💾 Зачем нужны файлы?

Бағдарлама аяқталғанда ЖЖҚ (RAM) ұмытылады. Деректерді дискке жазып, кейін қайта оқу үшін файлдарды қолданамыз: баптаулар, ойын прогресі, CSV есептер, JSON API жауаптары, логтар. Python-да файл ашу үшін open() қолданылады — ол файл объектін қайтарады. When a program ends RAM is wiped. To persist data to disk we use files: settings, game saves, CSV reports, JSON API responses, logs. Python opens files with open() — it returns a file object. Когда программа завершается, ОЗУ (RAM) стирается. Чтобы сохранить данные на диск и потом прочитать, используем файлы: настройки, сохранения, CSV-отчёты, JSON-ответы API, логи. В Python файл открывают через open() — получают файловый объект.

Построчно — экономно по памяти with open("data.txt", encoding="utf-8") as f: for line in f: print(line.rstrip()) # убрать '\n' в конце # 3. ✨ with конструкциясы — автоматты түрде файлды жабады, қате болса да! ✨ The with block auto-closes the file, even if an error occurs! ✨ Конструкция with автоматически закрывает файл, даже при ошибке!
