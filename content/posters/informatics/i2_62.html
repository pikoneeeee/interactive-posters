Шартты оператор: if / else

Conditional statement: if / else

Условный оператор: if / else

Не үшін шарт керек? Why do we need conditions? Зачем нужны условия?

Осы уақытқа дейін біздің бағдарлама сызықтық жұмыс істеді — жол артынан жол. Бірақ шынайы өмірде шешімдер жағдайға байланысты: «Жаңбыр жауып тұр ма? — Қолшатыр ал». Шартты оператор бағдарламаға «тармақталу» қабілетін қосады. Python-дағы if — «егер», else — «әйтпесе». Осы 2 сөзбен кез келген логикалық шешімді сипаттауға болады. Бірінші программалық if 1950 жылы ALGOL-58 тілінде пайда болған. So far our programs ran linearly, line after line. Real life needs choices based on the situation: «Is it raining? → take an umbrella». A conditional gives a program the power to branch. In Python: if means «if», else means «otherwise». With these two words any logical decision can be described. The first programmatic if appeared in ALGOL-58 in 1950. До этого программа работала линейно — строчка за строчкой. Но в жизни решения зависят от ситуации: «Идёт дождь? — возьми зонт». Условный оператор добавляет программе способность ветвиться. В Python: if — «если», else — «иначе». С этими словами можно описать любое логическое решение. Первый программный if появился в языке ALGOL-58 в 1950 г.
