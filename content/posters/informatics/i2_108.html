🎬 Ойынның «сахнасы» 🎬 The game «stage» 🎬 «Сцена» игры

Кез келген 2D ойын — қабат-қабат суреттер: ең төменгі — аспан/фон, ортаңғы — әлем объектілері (ағаш, тас), ең жоғарғы — кейіпкер мен UI. PyGame Surface объектісі арқылы жұмыс істейді: әрбір .png — жеке Surface. Оларды screen.blit(img, (x,y)) арқылы экранға қоямыз. Салу реті маңызды — кейінгісі үстіне түседі! Any 2-D game is a stack of image layers: bottom = sky/bg, middle = world objects (trees, rocks), top = player & UI. PyGame uses Surface objects — every .png becomes one. Draw them with screen.blit(img, (x,y)). Order matters: later calls paint on top! Любая 2D-игра — это слоёный пирог картинок: внизу — небо/фон, середина — объекты (деревья, камни), сверху — персонаж и UI. В PyGame всё — это Surface: каждая .png становится Surface. Рисуем через screen.blit(img, (x,y)). Порядок важен — поздняя картинка поверх!

🗂 Қабаттар тәртібі 🗂 Layer order 🗂 Порядок слоёв

блит реті ↓blit order ↓

Алдымен — артқы фон, кейін — әлем, соңынан — ойыншы және очки. Әр кадрда цикл төмен→жоғары қабатты қайта салады. First draw the background, then the world, finally the player and HUD. Every frame redraws all layers bottom-up. Сначала фон, потом мир, в конце игрок и UI. Каждый кадр всё перерисовывается снизу вверх.

🦸 Кейіпкер — Rect арқылы 🦸 Character via Rect 🦸 Персонаж через Rect

Rect — PyGame-дің «алтын құралы»: позиция + өлшем. Оны жылжыту, шектеу, соқтығысуды тексеру — бәрі бір жерде. Rect is PyGame's swiss-army tool: it holds position + size. Move, clamp, collide — all in one object. Rect — «швейцарский нож» PyGame: хранит позицию и размер. Движение, границы, столкновения — всё через него.

hero = pygame.image.load("hero.png").convert_alpha() hero_rect = hero.get_rect(center=(400, 300)) # жылжытуmoveдвигаем hero_rect.x += 5 hero_rect.y += 3 # экран шегінен шықпауclampвнутри экрана screen_rect = screen.get_rect() hero_rect.clamp_ip(screen_rect) # суретdrawрисуем screen.blit(hero, hero_rect)
