Массивтен элемент іздеу

Searching in an array

Поиск элемента в массиве

Іздеу есебі The search problem Задача поиска

Берілген: n элементтен тұратын массив a және іздеу мәні x. Табу керек: x-тің индексін немесе оның жоқтығын көрсету. Мысал: оқушылардың бағасынан «5.0» бағаны табу, телефон кітабынан есімді табу. Іздеу — ең жиі кездесетін компьютерлік амалдардың бірі (Google, БД, чат, ойынды ойлан!). Екі классикалық алгоритм: сызықтық O(n) және бинарлық O(log n). Given: array a of n elements and a target x. Return the index of x, or indicate it's missing. Examples: finding a mark of «5.0», looking up a name in a contact list. Search is one of the most common computer operations (Google, DBs, chats, games). Two classic algorithms: linear O(n) and binary O(log n). Дано: массив a из n элементов и искомое x. Надо: вернуть индекс x или сказать, что его нет. Примеры: найти оценку «5.0», контакт в телефоне. Поиск — одно из самых частых действий в компьютере (Google, БД, чаты, игры). Два классики: линейный O(n) и бинарный O(log n).

🚶 Сызықтық іздеу — O(n) 🚶 Linear search — O(n) 🚶 Линейный поиск — O(n)

Идея: басынан бастап әрбір элементті x-пен салыстырамыз. Тапсақ — индексті қайтарамыз, соңына жеткенше таппасақ — −1. Idea: compare every element with x from the start. Return the index when found; return −1 at the end if not. Идея: сравниваем каждый элемент с x подряд. Нашли — вернуть индекс; дошли до конца — −1.

def linear_search(a, x): for i in range(len(a)): if a[i] == x: return i return -1 print(linear_search([3, 1, 4, 1, 5, 9, 2], 5)) # 4

✅ Кез келген массивке жарамды (реттелмесе де). ⚠️ Үлкен массивта баяу. ✅ Works on any array (unsorted too). ⚠️ Slow for large n. ✅ Подходит любому массиву (даже несортированному). ⚠️ Медленный для больших n.

🏃 Бинарлық іздеу — O(log n) 🏃 Binary search — O(log n) 🏃 Бинарный поиск — O(log n)

Шарты: массив реттелген болуы керек! Идея: ортасын қара. x кіші болса — сол жағы, үлкен болса — оң жағы. Әр қадамда массив 2 есе қысқарады: 1 млн → 20 қадам! Pre-req: array must be sorted! Idea: compare with middle. If x < mid → go left; else → right. Each step halves the range: 1 M → 20 steps! Условие: массив отсортирован! Идея: смотрим середину. x меньше — влево, больше — вправо. Каждый шаг диапазон делится пополам: 1 млн → 20 шагов!

def binary_search(a, x): lo, hi = 0, len(a) - 1 while lo <= hi: mid = (lo + hi) // 2 if a[mid] == x: return mid elif a[mid] < x: lo = mid + 1 else: hi = mid - 1 return -1 # реттелген массивsorted arrayотсортированный a = [1, 3, 5, 7, 9, 11, 13, 15] print(binary_search(a, 9)) # 4
