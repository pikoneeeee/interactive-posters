PyGame — не? What is PyGame? Что такое PyGame?

PyGame — 2D ойындар жасауға арналған Python кітапханасы. Оны Пит Шиннерс 2000 жылы ашты. Астыңғы жағында SDL (Simple DirectMedia Layer) — сол кітапханада Valve Steam мен Half-Life жасалған. PyGame тегін, ашық кодты (LGPL), Windows · macOS · Linux · Raspberry Pi-де жұмыс істейді. Оқушыларға ыңғайлы: 50 жолмен бірінші ойынды жасай аласың! PyGame is a Python library for 2-D games, created by Pete Shinners in 2000. It wraps SDL (Simple DirectMedia Layer) — the same library Valve uses for Steam and Half-Life. PyGame is free, open-source (LGPL) and runs on Windows · macOS · Linux · Raspberry Pi. It's beginner-friendly: your first game in ~50 lines! PyGame — библиотека Python для создания 2D-игр. Её написал Пит Шиннерс в 2000 г. Под капотом — SDL (Simple DirectMedia Layer); на ней же сделаны Steam и Half-Life от Valve. PyGame бесплатна, open-source (LGPL) и работает на Windows · macOS · Linux · Raspberry Pi. Удобна для новичков: первая игра в ~50 строк!

🔁 Ойын циклі — PyGame-нің жүрегі 🔁 Game loop — heart of PyGame 🔁 Игровой цикл — сердце PyGame

import pygame, sys pygame.init() screen = pygame.display.set_mode((800, 600)) pygame.display.set_caption("Менің бірінші ойыным") clock = pygame.time.Clock() while True: # 1️⃣ оқиғаларeventsсобытия for event in pygame.event.get(): if event.type == pygame.QUIT: pygame.quit() sys.exit() # 2️⃣ логикаupdateлогика # … # 3️⃣ суретrenderотрисовка screen.fill((135, 206, 235)) # sky blue pygame.draw.circle(screen, (255,215,0), (400,300), 50) pygame.display.flip() clock.tick(60) # 60 FPS

🎮 3 қадам — Events → Update → Draw — әр секундта 60 рет қайталанады. 🎮 3 steps — Events → Update → Draw — repeat 60 × per second. 🎮 3 шага — Events → Update → Draw — повторяются 60 раз/сек.

🎯 Координат жүйесі 🎯 Coordinate system 🎯 Система координат

Координаттар экранның сол жоғарғы бұрышынан басталады. X — оңға, Y — төменге (математикадағыдай емес!). 800×600 экранда ең төменгі оң бұрышы — (799, 599). Coordinates start at the top-left corner. X goes right, Y goes down (unlike maths!). On an 800×600 screen the bottom-right is (799, 599). Координаты начинаются в левом верхнем углу. X — вправо, Y — вниз (не как в математике!). На экране 800×600 правый-нижний — (799, 599).
