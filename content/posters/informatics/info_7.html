1. What is Scratch?

1. Что такое Scratch?

Scratch – бұл код жазудың орнына түрлі-түсті блоктарды құрастыру арқылы программа жасайтын орта. Ол балаларға арналған.

Scratch is an environment where you create programs by assembling colorful blocks instead of writing code. Designed for kids.

Scratch – это среда, где программы создаются путем соединения разноцветных блоков вместо написания кода. Создан для детей.

2. Программа терезесі

2. Program Interface

2. Окно программы

Scratch терезесі негізгі 3 бөліктен тұрады: Сахна (нәтиже), Блоктар (кітапхана) және Скрипт алаңы (код жинау).

The Scratch window has 3 main parts: Stage (result), Blocks (library), and Script Area (coding).

Окно Scratch состоит из 3 частей: Сцена (результат), Блоки (библиотека) и Область скриптов (сборка кода).
