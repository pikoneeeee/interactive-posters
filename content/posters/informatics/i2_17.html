🎯 Кеңес: көпбұрыш үшін — әр бұрыш = 360° ÷ қабырға саны. Үшбұрыш → 120°, бесбұрыш → 72°. 🎯 Tip: for any regular polygon — each turn = 360° ÷ number of sides. Triangle → 120°, pentagon → 72°. 🎯 Подсказка: для многоугольника — угол = 360° ÷ число сторон. Треугольник → 120°, пятиугольник → 72°.
