Ауыстыру — не? What is swap? Что такое swap?

Ауыстыру (swap) — массивтегі екі элементтің орнын алмастыру. Бұл — алгоритмдердің кірпіші: сұрыптау, керіге айналдыру, Ханой мұнарасы, ойын тақтасы — бәрі swap-қа сүйенеді. Python-да бір қатарда жазылады: a, b = b, a. С немесе Java тілдерінде — үш қадам және уақытша айнымалы қажет. Swap O(1) — жылдам! Swap exchanges two elements in an array. It's the building block of algorithms: sorting, reversing, Tower of Hanoi, board games — all use swap. Python does it in one line: a, b = b, a. C or Java need three steps with a temp variable. Swap is O(1) — instant! Swap — обмен двух элементов массива. Это «кирпичик» алгоритмов: сортировки, разворот, Ханойские башни, ходы в играх — всё держится на swap. В Python делается в одну строку: a, b = b, a. В C и Java — три шага с временной переменной. Swap = O(1) — мгновенно!
