Интерактивті бағдарламаның 3 кезеңі бар: (1) енгізу — пайдаланушыдан деректерді ала, (2) өңдеу — есептеу, (3) шығару — нәтижені көрсету. Python-да енгізу үшін input(), шығару үшін print() қолданылады. Осы екеуі «пайдаланушы ↔ бағдарлама» диалогын құрайды. Олардың арқасында бағдарлама статикалық «құжат» емес, тірі құрал болады. Every interactive program has 3 stages: (1) input — get data from the user, (2) processing, (3) output — show the result. Python uses input() for input and print() for output. Together they create the «user ↔ program» dialogue. Thanks to them a program is not a static document but a live tool. У любой интерактивной программы 3 этапа: (1) ввод — получить данные от пользователя, (2) обработка, (3) вывод — показать результат. В Python для ввода — input(), для вывода — print(). Вместе они создают диалог «пользователь ↔ программа». Благодаря им программа — не документ, а живой инструмент.

👂 input() — пайдаланушыдан сұрау 👂 input() — ask the user 👂 input() — спрашиваем у пользователя

input() клавиатурадан жол күтеді. Пайдаланушы Enter басқанда — жазылған нәрсе str ретінде қайтарылады. Жақшаға сұраудың мәтінін қоюға болады. input() waits for a line. On Enter the text returns as a str. You can pass a prompt inside parentheses. input() ждёт строку с клавиатуры. После Enter введённый текст возвращается как str. В скобках можно указать подсказку.

name = input("Атыңды жаз: Your name: Как тебя зовут: ") print("Сәлем, Hello, Привет, " + name)

⚠️ Маңызды — әрдайым str!Always returns str!Всегда возвращает str!
