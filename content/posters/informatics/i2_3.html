Мәтінді кодтау және кері оқу

Encoding and decoding text

Кодирование и декодирование текста

🔤 Кодтау дегеніміз не? 🔤 What is encoding? 🔤 Что такое кодирование?

Кодтау — хабарды бір түрден екінші түрге айналдыру. Мысалы, әріпті санға, сөзді нышанға, сурет пен дыбысты — компьютер түсінетін 0 мен 1-ге. Декодтау — кері процесс: код → бастапқы хабар. Күнделікті өмірде біз үнемі кодтаймыз: жазу — дыбыстан әріпке, смс — сөздерден қысқа жазуға, бағдаршам — нұсқаудан түске. Encoding is turning a message from one form into another. A letter becomes a number, a word a symbol, a picture or sound — a sequence of 0s and 1s the computer understands. Decoding is the reverse: code → original message. We encode every day: writing (sound→letter), SMS (word→short form), traffic light (rule→colour). Кодирование — превращение сообщения из одной формы в другую. Буква становится числом, слово — значком, картинка и звук — длинной цепочкой 0 и 1, понятной компьютеру. Декодирование — обратный процесс: код → исходное сообщение. Мы кодируем каждый день: пишем (звук→буква), SMS (слово→сокращение), светофор (правило→цвет).

🔁 Кодтау схемасы 🔁 Encoding scheme 🔁 Схема кодирования

📨 Бастапқы хабар кодтау ережесі арқылы кодқа айналады, беріледі, кері тарапта кері ереже арқылы қайта оқылады. 📨 The source message is turned into code by an encoding rule, transmitted, and the receiver uses the reverse rule to decode it back. 📨 Исходное сообщение по правилу кодирования становится кодом, передаётся, а получатель по обратному правилу возвращает его в текст.

🔢 Әріптің коды — әліпбидегі нөмір 🔢 Letter code — position in the alphabet 🔢 Код буквы — её номер в алфавите

Ең қарапайым кодтау — әрбір әріпке нөмір беру. Орыс әліпбиінде А=1, Б=2, В=3, …, Я=33. The simplest code — give every letter its number. In English A=1, B=2, C=3, …, Z=26. Простейшее кодирование — присвоить каждой букве её номер. В русском А=1, Б=2, В=3, …, Я=33.

💻 Компьютер қалай кодтайды? 💻 How a computer encodes? 💻 Как кодирует компьютер?

Компьютер үшін ең ыңғайлысы — ASCII (американдық стандарт). Ол әр таңбаға 0-127 аралығындағы сан береді. Мысалы, бас әріп «A» = 65, кіші «a» = 97, сан «0» = 48, бос орын = 32. Ары қарай компьютер ол санды екілік жүйеге аударады: 65 → 1000001. A computer uses ASCII — an American standard. It gives every character a number 0–127. For example, 'A' = 65, 'a' = 97, digit '0' = 48, space = 32. Then the number becomes binary: 65 → 1000001. Компьютер использует таблицу ASCII (американский стандарт). Каждому символу соответствует число 0–127. Например, «A» = 65, «a» = 97, цифра «0» = 48, пробел = 32. Потом число переводится в двоичный код: 65 → 1000001.
