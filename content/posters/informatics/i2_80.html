Цикл for

for — «тізімнен өту» for — «walk the list» for — «пройти по списку»

for циклі — белгілі тізімнің/аралықтың әр элементіне бір рет қатесіз барады. Python-дағы for C/Java-дан ерекше: тек «әр элемент үшін» форматы бар — «үшін-тізбек» (for-each). Ол есептегіш-айнымалыны саған автоматты береді, қадамды қадамдауды ұмытпайсың. Қайта-қайта жиі қолданылатын конструкция болғандықтан, Python-да for бүкіл кодтың ~40%-ын құрайды (GitHub статистикасы, 2023). for walks through every element of a known sequence. Python's for differs from C/Java — it is only a for-each: the counter is handed to you automatically. According to GitHub stats (2023), for accounts for ~40% of all Python loops. for проходит по каждому элементу известной последовательности. В Python это только «for-each»: счётчик выдаётся автоматически — забыть обновить его невозможно. По статистике GitHub 2023 г. на for приходится ~40% всех Python-циклов.

🔁 Кірістірілген for (nested) 🔁 Nested for 🔁 Вложенный for

Бір for ішінде екінші for → 2D есептеу. Көбейту кестесі, матрица, Пифагор. for inside for → 2D work: multiplication table, matrix. for внутри for → 2D-обход: таблица умножения, матрица.

for i in range(1, 6): for j in range(1, 6): print(i * j, end="\t") print() # 1 2 3 4 5 # 2 4 6 8 10 # ...
