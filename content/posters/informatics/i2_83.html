else in loops

else в циклах

Циклде else? Қалай? else in a loop? What? else в цикле? Как?

Python-ның ерекше мүмкіндігі: else блогы цикл ішінде де болуы мүмкін. Бұл қарапайым if/else емес! Ережесі қарапайым: else орындалады, егер цикл break-сіз аяқталса. Яғни: «циклды толық айналдым ба?» → else. «break-пен шықтым» → else өткізіледі. Бұл идея тек Python-да және Rust-та бар — C, Java, JS-те жоқ. Монти Python-ның өзінше «әзілі»! Қолдану: іздеу циклдарынан кейін «табылмады» деген хабарды жазу. Python has a unique feature: else can be attached to a loop. It is not the usual if/else! Rule: else runs only if the loop finished without break. «Looped all the way?» → else. «Left via break?» → else skipped. Only Python and Rust have this — not C, Java, JS. It's even been called «Python's odd gift». Typical use: after a search loop print «not found». У Python есть уникальная фича: else можно прицепить к циклу. Это не обычный if/else! Правило: else выполняется только если цикл завершился БЕЗ break. «Прошёл цикл до конца?» → else. «Вышел через break?» → else пропускается. Такого нет ни в C, ни в Java, ни в JS — только Python и Rust. Применение: после поискового цикла печатаем «не найдено».

🐍 Синтаксис 🐍 Syntax 🐍 Синтаксис

for + else

for x in range(5): print(x) else: print("Done!") # 0 1 2 3 4 Done!

while + else

i = 0 while i < 3: print(i) i += 1 else: print("Ended") # 0 1 2 Ended
