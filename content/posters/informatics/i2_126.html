Работа со строками в Python

📝 Жол — не? 📝 What is a string? 📝 Что такое строка?

Жол (str) — Unicode таңбаларының өзгермейтін (immutable) тізбегі. Тырнақшалармен жазылады: 'hi', "hi", үш тырнақша """...""" — көп жолды. Python-да жол — тізбекті тип: индекс, срез, len(), in қолданады. A string (str) is an immutable sequence of Unicode characters. Written with quotes: 'hi', "hi"; triple-quoted """...""" for multi-line. In Python a string is a sequence type: supports indexing, slicing, len(), in. Строка (str) — неизменяемая последовательность Unicode-символов. Записывается в кавычках: 'hi', "hi"; тройные """...""" — многострочные. В Python строка — последовательный тип: индексы, срезы, len(), in.
