ASCII (American Standard Code for Information Interchange) — 7 бит, 128 таңба: ағылшын әріптері, сандар, тыныс белгілері, басқару кодтары. Тек латын әліпбиі — орыс, қазақ, қытай таңбалары жоқ! ASCII (American Standard Code for Information Interchange) — 7 bits, 128 characters: English letters, digits, punctuation, control codes. Latin only — no Cyrillic, Kazakh, Chinese! ASCII (American Standard Code for Information Interchange) — 7 бит, 128 символов: латинские буквы, цифры, знаки, управляющие коды. Только латиница — нет кириллицы, казахского, китайского!

Unicode (1991) — 149 000+ таңбаны қамтиды: латын, кирилл, араб, қытай, эмодзи, музыка белгілері. Әр таңбаға U+ нөмірі беріледі (код-пойнт). Мысалы: A = U+0041, Ә = U+04D9, 🐱 = U+1F431. Unicode (1991) covers 149 000+ characters: Latin, Cyrillic, Arabic, Chinese, emoji, musical notes. Each gets a U+ number (code-point). E.g. A = U+0041, Ә = U+04D9, 🐱 = U+1F431. Unicode (1991) — 149 000+ символов: латиница, кириллица, арабский, китайский, эмодзи, музыкальные ноты. Каждому даётся номер U+ (код-пойнт). Например: A = U+0041, Ә = U+04D9, 🐱 = U+1F431.

The most popular is UTF-8 (98% of the web). Unicode — это просто таблица номеров. Чтобы сохранить их в байтах, нужна форма кодирования. Самая популярная — UTF-8 (98% веба).
