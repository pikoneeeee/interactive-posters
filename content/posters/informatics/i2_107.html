Creating the game window

Создание окна игры

🪟 Ең қысқа PyGame-код 🪟 Shortest PyGame code 🪟 Минимальный PyGame-код

Терезе — кез келген ойынның бастапқы тасы. 10 жолдан кем кодпен бос, түрлі-түсті, FPS-мен тұрақты жұмыс істейтін терезе алуға болады. Сенің кейіпкерлерің, артқы фондарың, ойын механикасы — бәрі осы негіздің үстіне құрылады. The window is the foundation of any game. In under 10 lines you can open an empty, coloured, 60 FPS window. All characters, backgrounds and game logic will sit on this base. Окно — фундамент любой игры. В 10 строк кода уже есть пустое, цветное, стабильные 60 FPS окно. Все персонажи, фоны и механики строятся на этой основе.

import pygame, sys pygame.init() screen = pygame.display.set_mode((800, 600)) pygame.display.set_caption("My Game") clock = pygame.time.Clock() while True: for e in pygame.event.get(): if e.type == pygame.QUIT: pygame.quit(); sys.exit() screen.fill((30, 41, 59)) # dark pygame.display.flip() clock.tick(60) # 60 FPS

🔤 Мәтін 🔤 Rendering text 🔤 Отрисовка текста

font = pygame.font.SysFont("Arial", 36, bold=True) img = font.render("Score: 42", True, (255,255,255)) screen.blit(img, (20, 20))

💡 render(text, antialias, color) — мәтінді Surface қылады, blit-пен экранға қоямыз. 💡 render returns a Surface; blit places it on screen. 💡 render возвращает Surface, а blit рисует её на экране.
