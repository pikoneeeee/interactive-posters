Не үшін әр түрлі жады бар? Why so many kinds of memory? Зачем столько видов памяти?

Компьютерде жалғыз жады емес — пирамида. Төменде — көлемді, бірақ баяу жады (HDD, SSD), жоғарыда — аз көлемді, бірақ найзағайдай жылдам (кэш, регистрлер). Әр саты өз орнын алады: процессорға бір сөз қажет болса, ол оны миллиардтан аз уақытта табуы керек. Сондықтан инженерлер 4 деңгейлі жады жүйесін құрған: қайсысы жылдам болса — сонша кіші, бірақ ең қымбат. A computer doesn't have one memory — it has a pyramid. At the bottom: big but slow storage (HDD, SSD). At the top: small but lightning-fast memory (cache, registers). Each layer has its purpose — the CPU must fetch a value in nanoseconds. So engineers built a 4-level hierarchy: faster → smaller → more expensive. В компьютере не одна память — целая пирамида. Внизу — большая, но медленная (HDD, SSD), вверху — крошечная, но молниеносная (кэш, регистры). У каждого уровня своя роль: процессору нужно достать число за наносекунды. Поэтому инженеры построили 4-уровневую иерархию: быстрее — меньше — дороже.

ОЗУ · RAM

Оперативті жадыRandom-Access MemoryОперативная память

Процессор жұмыс істеп жатқан деректерді сақтайды. Тез оқу/жазу. Компьютерді өшірсе — бәрі жойылады (volatile). Көбі: DDR4, DDR5. Holds the data the CPU is actively working on. Fast read/write. Turn off the PC and everything is lost (volatile). Types: DDR4, DDR5. Держит данные, с которыми процессор работает сейчас. Быстрая. Выключил — всё стёрлось (энергозависимая). Типы: DDR4, DDR5.

ПЗУ · ROM

Тек оқу жадыRead-Only MemoryПостоянная память

Зауытта бір рет жазылған деректер. Өзгертілмейді немесе өте сирек. Онда BIOS/UEFI — компьютерді іске қосатын бағдарлама тұрады. Data written at the factory. Cannot be changed (or very rarely). It keeps BIOS/UEFI — the program that boots the PC. Данные записаны на заводе, изменить нельзя (или очень редко). Здесь живёт BIOS/UEFI — программа запуска ПК.

  • ⏱️ Жылдамдық:Speed:Скорость: орташаmediumсредняя

Cache

Аса жылдам жадыUltra-fast SRAMСверхбыстрая память

Процессордың ішінде орналасқан. RAM-нан 100 есе жылдам. Жиі қолданылатын деректер кэште тұрады. 3 деңгейі бар: L1 (кіші, жылдам), L2 (орташа), L3 (үлкен). Inside the CPU. 100× faster than RAM. Stores the most-used data. 3 levels: L1 (tiny, fastest), L2, L3 (biggest). Находится внутри процессора. В 100 раз быстрее ОЗУ. Хранит самые нужные данные. 3 уровня: L1, L2, L3.

  • ⏱️ ~ 1 нсnsнс
  • 📦 L1: 64 KB · L2: 256 KB–1 MB · L3: 4–32 MB
  • 💲 Ең қымбатMost expensiveСамая дорогая

ВЗУ · Storage

Сыртқы жинақтау жадыExternal storageВнешняя память

Файлдар үшін: фото, бейне, бағдарламалар. Компьютерді өшірсе — сақталады. Түрлері: HDD (магнитті), SSD (флеш), USB-флешка, SD-карта, DVD, облақ. For files: photos, videos, programs. Turn off — data stays. Types: HDD (magnetic), SSD (flash), USB stick, SD card, DVD, cloud. Для файлов: фото, видео, программы. Выключил — данные остаются. Типы: HDD, SSD, USB, SD, DVD, облако.

  • ⏱️ HDD ~100 МБ/сMB/sМБ/с · SSD ~5 ГБ/сGB/sГБ/с
  • 📦 256 GB – 16 TB
  • 🔒 Non-volatile

🎯 Өмірлік талдау: неге RAM аз? 🎯 Real-world: why is RAM so small? 🎯 Из жизни: почему ОЗУ так мало?

16 ГБ RAM — 1 ТБ SSD-мен салыстырғанда 60 есе аз. Бірақ ОЖ-сыз ешнәрсе жүрмейді! Процессор тек RAM-дан нұсқауларды оқиды. Файл SSD-да тұрса — алдымен RAM-ға көшіріледі, сонан соң орындалады. Сондықтан RAM үлкенірек болған сайын, компьютер жылдам жұмыс істейді: көп бағдарламаны бір уақытта ұстау мүмкіндігі артады. 16 GB RAM is 60× less than a 1 TB SSD. But without RAM nothing runs! The CPU reads instructions only from RAM. A file on SSD is first copied into RAM, then executed. That's why more RAM = snappier PC: you can keep more programs open at once. 16 ГБ ОЗУ — в 60 раз меньше, чем 1 ТБ SSD. Но без ОЗУ ничего не работает! Процессор читает команды только из ОЗУ. Файл с SSD сначала копируется в ОЗУ, а потом выполняется. Поэтому больше ОЗУ = быстрее компьютер: больше программ одновременно.
