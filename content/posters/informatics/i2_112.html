Подсчёт очков и игровой цикл

🔁 Ойын циклі — жүрек 🔁 Game loop — the heart 🔁 Игровой цикл — сердце

Әр ойын — үнемі қайталанатын 3 қадамнан тұрады: оқиғаларды оқу → күйді жаңарту → сурет салу. Бұл цикл секундына 60 рет айналады, ешқашан тоқтамайды. Ұпай (score) — ойыншының жетістігі. Ол — айнымалы, collision немесе таймерде өседі, ал ең жоғары ұпай (high-score) файлға сақталады. Every game is a loop that repeats 3 steps: read events → update state → render. It runs 60 times per second forever. The score is the player's progress — just a variable that grows on collision or timer. The high-score is persisted to a file. Любая игра — это цикл из 3 шагов: чтение событий → обновление → отрисовка. Он крутится 60 раз в секунду непрерывно. Очки — прогресс игрока, обычная переменная, растёт на столкновении или по таймеру. Рекорд сохраняется в файл.

import pygame, sys, random pygame.init() screen = pygame.display.set_mode((800, 600)) clock = pygame.time.Clock() font = pygame.font.SysFont("Arial", 28, bold=True) player = pygame.Rect(380, 280, 40, 40) coins = [pygame.Rect(random.randint(0,760), random.randint(0,560), 24, 24) for _ in range(8)] score, running = 0, True while running: for e in pygame.event.get(): if e.type == pygame.QUIT: running = False k = pygame.key.get_pressed() player.x += (k[pygame.K_RIGHT] - k[pygame.K_LEFT]) * 5 player.y += (k[pygame.K_DOWN] - k[pygame.K_UP]) * 5 player.clamp_ip(screen.get_rect()) hit = player.collidelist(coins) if hit != -1: coins.pop(hit); score += 10 if not coins: running = False screen.fill((15,23,42)) for c in coins: pygame.draw.ellipse(screen,(253,224,71),c) pygame.draw.rect(screen,(14,165,233),player,border_radius=6) screen.blit(font.render(f"Score: {score}",1,(255,)*3),(20,20)) pygame.display.flip() clock.tick(60) pygame.quit(); sys.exit()
