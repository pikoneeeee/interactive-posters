Linear algorithms in Python

Линейные алгоритмы на Python

Сызықтық алгоритм дегеніміз не? What is a linear algorithm? Что такое линейный алгоритм?

Сызықтық алгоритм — қадамдары жоғарыдан төменге, бір рет, тармақсыз орындалатын алгоритм. Бұл ең қарапайым түр: қадамдарды «секіріп өту» немесе «қайталау» жоқ. Мысалы: «есікке бар → кілтті ал → ашу → ішке кір». Python-да бұл бағдарламаны жол артынан жол жазамыз. Барлық рецепттер, нұсқаулықтар, математикалық формулалар — көбіне сызықтық. A linear algorithm runs top-to-bottom, once, with no branches. It is the simplest kind: nothing is skipped or repeated. Example: «walk to the door → take the key → unlock → enter». In Python we just write statements line by line. Most recipes, manuals and maths formulas are linear. Линейный алгоритм — шаги идут сверху вниз, один раз, без разветвлений. Это самый простой вид: ничего не пропускается и не повторяется. Пример: «подойди к двери → возьми ключ → открой → войди». В Python пишется строчка за строчкой. Большинство рецептов, инструкций и формул — линейные.
