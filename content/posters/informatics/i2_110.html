PyGame-де пернеге 2 тәсілмен жауап береміз: «оқиғалар» (events) — перне бір рет басылғанда (секіру, оқ ату, мәзір), және «күйі» (state) — перне ұсталып тұрғанда (жүру, ұшу). Дұрыс стильді таңдау — ойынның сезімін анықтайды. Marioдегі секіру — event, жүру — state! PyGame offers two ways to read keys: events (a key is just pressed — for jump, shoot, menu) and state (currently held down — for walking, flying). Picking the right style defines how the game feels. In Mario, jump = event, running = state! В PyGame клавиши читаются двумя способами: события (клавиша только что нажата — прыжок, выстрел, меню) и состояние (клавиша удерживается — ходьба, полёт). Выбор стиля определяет ощущения игры. У Марио: прыжок = event, бег = state!

🧩 Толық мини-мысал 🧩 Complete mini-example 🧩 Полный мини-пример

import pygame, sys pygame.init() screen = pygame.display.set_mode((800, 600)) clock = pygame.time.Clock() player = pygame.Rect(380, 280, 40, 40) SPEED = 5 while True: for e in pygame.event.get(): if e.type == pygame.QUIT: sys.exit() k = pygame.key.get_pressed() if k[pygame.K_LEFT] or k[pygame.K_a]: player.x -= SPEED if k[pygame.K_RIGHT] or k[pygame.K_d]: player.x += SPEED if k[pygame.K_UP] or k[pygame.K_w]: player.y -= SPEED if k[pygame.K_DOWN] or k[pygame.K_s]: player.y += SPEED player.clamp_ip(screen.get_rect()) screen.fill((15, 23, 42)) pygame.draw.rect(screen, (14, 165, 233), player, border_radius=8) pygame.display.flip() clock.tick(60)

💡 clamp_ip — ойыншыны экран шегінде ұстап тұрады. «or K_a» — WASD + arrows бірге жұмыс істеуі. 💡 clamp_ip keeps player inside the screen. «or K_a» lets WASD + arrows both work. 💡 clamp_ip удерживает игрока в пределах экрана. «or K_a» — работают и WASD, и стрелки.
