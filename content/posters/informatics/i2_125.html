Functions and procedures

Функции и процедуры в Python

🧩 Функция — не? 🧩 What is a function? 🧩 Что такое функция?

Функция — атауы бар код блогы: бір рет жазасың, мыңдаған рет шақырасың. Ол DRY (Don't Repeat Yourself) принципін орындайды, бағдарламаны оқу, тестілеу, жөндеу оңай етеді. Python-да функция def сөзімен анықталады. Мән қайтармаса — процедура деп атайды (қайтаратын мәні None). A function is a named block of code: write once, call thousands of times. It enforces DRY (Don't Repeat Yourself) and makes code easier to read, test, debug. Python functions are defined with def. A function that returns nothing is called a procedure (returns None). Функция — блок кода с именем: пишешь один раз, вызываешь тысячи. Она реализует принцип DRY (Don't Repeat Yourself), делает код проще для чтения, тестирования и отладки. В Python функция определяется словом def. Если значение не возвращается — это процедура (возвращает None).
