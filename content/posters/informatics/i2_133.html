📊 Агрегация — жалпылау 📊 Aggregation — summarising 📊 Агрегация — обобщение

5 негізгі функция: COUNT, SUM, AVG, MIN, MAX. GROUP BY оларды топтар бойынша есептеуге мүмкіндік береді. Five key functions: COUNT, SUM, AVG, MIN, MAX. GROUP BY computes them per group. Пять ключевых функций: COUNT, SUM, AVG, MIN, MAX. GROUP BY считает их по группам.

-- общая статистика SELECT COUNT(*), AVG(mark), MAX(mark) FROM marks; -- средняя оценка по каждому классу SELECT class_id, AVG(mark) AS avg_mark, COUNT(*) AS n FROM marks GROUP BY class_id HAVING AVG(mark) > 4.0 -- фильтр групп ORDER BY avg_mark DESC;

💡 WHERE — жолдарды, HAVING — топтарды сүзеді! 💡 WHERE filters rows, HAVING filters groups! 💡 WHERE фильтрует строки, HAVING — группы!

🔗 JOIN — кестелерді біріктіру 🔗 JOIN — combining tables 🔗 JOIN — соединение таблиц

JOIN — бірнеше кестенің мәліметтерін бір жолға біріктіреді. Байланыс PK/FK арқылы: ON t1.fk = t2.pk. JOIN merges data from several tables into one row. Linked by PK/FK: ON t1.fk = t2.pk. JOIN склеивает данные из нескольких таблиц в одну строку. Связь по PK/FK: ON t1.fk = t2.pk.

-- INNER JOIN — только совпадения в обеих SELECT s.name, c.name AS class FROM students s INNER JOIN classes c ON s.class_id = c.id; -- LEFT JOIN — все студенты, даже без класса SELECT s.name, c.name AS class FROM students s LEFT JOIN classes c ON s.class_id = c.id;

🏗 3 кестелік күрделі сұраныс 🏗 3-table complex query 🏗 Сложный запрос с 3 таблицами

📚 Әр сыныптың «Математика» орташа бағасы (4.0-тан жоғары): 📚 Average «Maths» mark per class (above 4.0): 📚 Средняя оценка по «Математике» по каждому классу (выше 4.0):

SELECT c.name AS class, ROUND(AVG(m.mark), 2) AS avg_mark, COUNT(DISTINCT s.id) AS students FROM marks m JOIN students s ON m.student_id = s.id JOIN classes c ON s.class_id = c.id JOIN subjects su ON m.subject_id = su.id WHERE su.name = 'Математика' AND m.date >= '2024-09-01' GROUP BY c.name HAVING AVG(m.mark) > 4.0 ORDER BY avg_mark DESC LIMIT 10;
