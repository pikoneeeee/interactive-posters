Сұрыптау: көпіршік пен таңдау

Sorting: bubble & selection

Сортировка: пузырёк и выбор

Сұрыптау — не? What is sorting? Что такое сортировка?

Сұрыптау — массивтің элементтерін реттелген тәртіппен қою (өсу немесе кему бойынша). Бұл — информатикадағы ең көне есеп: Herman Hollerith 1890 жылы АҚШ халық санағында перфокарталарды механикалық сұрыптап, дамуды ұштады. Бүгінде әрбір іздеу жүйесі, БД, таблица, ойын лидерборды сұрыптауды қолданады. Жүздеген әдіс бар, бірақ 2 классиканы бәрі үйренеді: көпіршік және таңдаумен. Sorting arranges an array in a specific order (ascending or descending). It's one of the oldest CS problems — Herman Hollerith's 1890 US census machine sorted punch cards mechanically. Today every search engine, DB, spreadsheet and leaderboard relies on sorting. Hundreds of algorithms exist but everyone starts with the 2 classics: bubble and selection. Сортировка — расстановка элементов массива в определённом порядке (возр./убыв.). Одна из древнейших задач в информатике: машина Холлерита (1890, перепись США) уже сортировала перфокарты. Сегодня любая поисковая система, БД, таблица и таблица рекордов — держится на сортировке. Алгоритмов сотни, но начинают все с 2 классик: пузырьком и выбором.

🫧 Көпіршікті сұрыптау (Bubble) 🫧 Bubble sort 🫧 Пузырьковая

Идея: көршілес жұпты салыстыр. Сол > оң болса — swap. Өтуді n рет қайтала — ең үлкен әр өту сайын соңына «көпіршіктенеді». Idea: compare each adjacent pair; if left > right — swap. Repeat n times — on every pass the biggest «bubbles» to the end. Идея: сравниваем соседей. Левый > правого — меняем. За n проходов самое большое «всплывает» в конец.

def bubble(a): n = len(a) for i in range(n - 1): swapped = False for j in range(n - 1 - i): if a[j] > a[j + 1]: a[j], a[j + 1] = a[j + 1], a[j] swapped = True if not swapped: break # оңтайландыруearly-exitоптимизация

🎯 Таңдаумен сұрыптау (Selection) 🎯 Selection sort 🎯 Сортировка выбором

Идея: әрбір өтуде ең кіші элементті тап → оны сол жақ шекараға алмастыр. Idea: on each pass find the minimum and swap it to the left boundary. Идея: на каждом проходе находим минимум и ставим на левую границу.

def selection(a): n = len(a) for i in range(n - 1): mn = i for j in range(i + 1, n): if a[j] < a[mn]: mn = j a[i], a[mn] = a[mn], a[i]
