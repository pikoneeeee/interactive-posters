Таблицы истинности

📋 Ақиқаттық кесте — не? 📋 What is a truth table? 📋 Что такое таблица истинности?

Ақиқаттық кесте — логикалық өрнектің барлық мүмкін кіріс мәндері мен шығыстарын көрсететін кесте. 1 өрнек = 1 кесте. Ол күмәнді тексерудің ең қарапайым жолы: егер барлық жолда шығыс 1 болса — тавтология (әрдайым ақиқат), барлығы 0 болса — қайшылық. Кіріс саны n болса — кестеде 2ⁿ жол болады: 2 айнымалы → 4 жол, 3 → 8, 4 → 16. A truth table lists every possible input combination of a logical expression and its output. One formula = one table. It's the simplest proof engine: if every row outputs 1, the formula is a tautology; if all are 0, it's a contradiction. With n inputs the table has 2ⁿ rows: 2 vars → 4, 3 → 8, 4 → 16. Таблица истинности перечисляет все наборы входов логического выражения и его выход. Одна формула = одна таблица. Это простейший движок доказательства: если во всех строках 1 — тавтология; все 0 — противоречие. Для n входов получим 2ⁿ строк: 2 → 4, 3 → 8, 4 → 16.
