Python дегеніміз не? What is Python? Что такое Python?

Python — әлемдегі ең танымал бағдарламалау тілдерінің бірі. 1991 жылы голландиялық Гвидо ван Россум ойлап тапқан. Атауы «Python» (орысша «питон» — жылан) Monty Python британдық юмор шоуынан алынған. Ол тілді адам тіліне ұқсас, оқуға оңай етіп жасады. Бүгінде Python-да YouTube, Instagram, Spotify, ал Google-дің көп бөлігі — Dropbox, NASA-ның ғарыш зерттеулері, ЖИ (ChatGPT) жазылған. 2024 жылы Python 10 жыл қатарынан №1 тіл IEEE рейтингінде. Python is one of the world's most popular programming languages. Created in 1991 by Dutch developer Guido van Rossum. The name "Python" comes from the British comedy show Monty Python, not the snake. He designed it to read almost like English. Today Python powers YouTube, Instagram, Spotify, most of Google, Dropbox, NASA research, and AI (ChatGPT). In 2024 Python was #1 for the 10th year in a row (IEEE Spectrum). Python — один из самых популярных языков программирования в мире. Его создал в 1991 году голландец Гвидо ван Россум. Название «Python» — от британского шоу Monty Python, а не от змеи. Он сделал язык похожим на английский, чтобы его было легко читать. Сегодня на Python работают YouTube, Instagram, Spotify, значительная часть Google, Dropbox, NASA, ИИ (ChatGPT). В 2024 году Python — №1 10-й год подряд по версии IEEE Spectrum.

📐 Синтаксис ережелері 📐 Syntax rules 📐 Правила синтаксиса

1. Шегіністер (indent) — өте маңызды!Indentation matters!Отступы — это синтаксис!

Блоктар {}-мен емес, 4 бос орынмен белгіленеді. Басқа тілдерде бұл стиль ғана, ал Python-да — заң!Blocks are marked by 4 spaces, not by {}. In other languages it's style — in Python it's law!Блоки отмечаются 4 пробелами, а не {}. В других языках это стиль, а в Python — закон!

if x > 0: print("плюс") # 4 бос орынspacesпробела else: print("минус")

2. Нүкте-үтір керек емесNo semicolonsНе нужны ;

Әр пәрмен — жеке жол. Нүкте-үтір қолданылмайды.One command per line. Semicolons aren't used.Одна команда — одна строка. Точка с запятой не нужна.

x = 5 y = 10 print(x + y)

3. Регистр маңызды (case sensitive)Case sensitiveРегистр важен

Аты мен ATY мен aty — 3 түрлі айнымалы.name, Name and NAME are 3 different variables.name, Name и NAME — 3 разные переменные.

name = "Aidar" # ✅ Name = "Aidar" # басқа айнымалы!different!другая переменная!

4. Түсініктеме — # арқылыComments start with #Комментарии через #

Python #-тен кейін жолдың соңына дейін оқымайды.Python ignores everything after # to end of line.Python игнорирует всё после # до конца строки.
