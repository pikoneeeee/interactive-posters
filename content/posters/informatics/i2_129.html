🕸 Граф — не? 🕸 What is a graph? 🕸 Что такое граф?

Граф — төбелер (vertex) мен қабырғалар (edge) жиыны. Қалалар + жолдар, әлеуметтік желі достар, веб-беттер + гиперсілтемелер — барлығы графтар. Leonhard Euler 1736 жылы Кёнигсберг көпірлері есебінен граф теориясын бастады. Бағыттаулы (1→2) және бағытталмаған (1↔2), салмақты (көліктік шығын) графтар бар. A graph is a set of vertices connected by edges. Cities + roads, social friends, web + hyperlinks — all graphs. Leonhard Euler founded graph theory in 1736 (Königsberg bridges). Graphs can be directed (1→2) or undirected (1↔2), weighted (distance, cost) or unweighted. Граф — набор вершин, связанных рёбрами. Города и дороги, друзья в соцсети, веб и ссылки — всё графы. Теория графов основана Леонардом Эйлером в 1736 г. (кёнигсбергские мосты). Бывают ориентированные (1→2) и неориентированные (1↔2), взвешенные (стоимость, расстояние) и нет.

🌊 BFS — кең бойынша іздеу 🌊 BFS — Breadth-First Search 🌊 BFS — поиск в ширину

Бастапқы төбеден «қабат-қабат» таралады: алдымен көршілер, сосын көршілердің көршілері. Кезек (queue, FIFO) қолданады. Ең қысқа жолды қадам саны бойынша табады. Spreads layer by layer from the start: first direct neighbours, then neighbours of neighbours. Uses a queue (FIFO). Finds the shortest path in terms of edges. Распространяется от старта «по слоям»: сначала соседи, потом соседи соседей. Использует очередь (FIFO). Находит кратчайший путь по числу рёбер.

from collections import deque def bfs(graph, start): visited = {start} q = deque([start]) while q: v = q.popleft() # вынимаем из начала print(v, end=" ") for u in graph[v]: if u not in visited: visited.add(u) q.append(u) # кладём в конец G = {"A":["B","D"], "B":["A","C","D"], "C":["B","E"], "D":["A","B","E"], "E":["C","D"]} bfs(G, "A") # A B D C E

🏞 DFS — тереңдікке іздеу 🏞 DFS — Depth-First Search 🏞 DFS — поиск в глубину

Бір жолмен мүмкіндігінше тереңге кетеді, тұйыққа келсе — артқа оралып (backtrack) басқа тармаққа. Стек (LIFO) немесе рекурсия қолданады. Лабиринттерді, циклдерді, топологиялық сұрыптауды табады. Goes as deep as possible along one branch, then backtracks. Uses a stack (LIFO) or recursion. Great for mazes, cycle detection, topological sort. Идёт как можно глубже по одной ветви, потом «откатывается» (backtrack). Использует стек (LIFO) или рекурсию. Подходит для лабиринтов, поиска циклов, топосортировки.

def dfs(graph, v, visited=None): if visited is None: visited = set() visited.add(v) print(v, end=" ") for u in graph[v]: if u not in visited: dfs(graph, u, visited) dfs(G, "A") # A B C E D
