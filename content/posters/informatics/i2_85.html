Есептің қойылуы және моделі

Problem statement & model

Постановка задачи и модель

«Есепті қой» деген не? What is «problem statement»? Что такое постановка задачи?

Ұлы инженер Ричард Фейнман: «Есеп қойылған кезде — ол жарты шешілген». Басымдылық — кодты жазбастан бұрын не істеу керек, қандай деректер бар, қандай нәтиже қажет екенін анықтау. Бағдарламашылар үшін бұл фаза «analysis» деп аталады. Есепті нақты қою үшін біз оны математика/информатика тіліне аударамыз, модель жасаймыз. Модельсіз код — бағытсыз қайық! Engineer Richard Feynman: «A problem well stated is half solved». Before writing any code we need to understand what must be done, what data we have and what result is expected. Programmers call this phase «analysis». We translate the task into the language of maths/CS — we build a model. Code without a model is a boat without a rudder! Великий инженер Ричард Фейнман говорил: «Хорошо поставленная задача — наполовину решённая». До написания кода нужно понять что сделать, какие есть данные, какой результат нужен. Программисты называют этот этап «анализ». Мы переводим задачу на язык математики/информатики — строим модель. Код без модели — лодка без руля!

🧩 Модель — ол не? 🧩 What is a model? 🧩 Что такое модель?

Модель — есептің «жеңілдетілген картинкасы». Тек маңызды жақтарын қалдырады, қалғанын тастайды. Қағаздан жасалған ұшақ — нағыз Boeing-нің моделі. A model is a simplified picture of the problem. Keep only the essentials, drop the rest. A paper plane is a model of a Boeing. Модель — упрощённая картинка задачи. Оставляет только самое важное, лишнее — выбрасывает. Бумажный самолётик — модель Boeing.

📋 ШартTaskУсловие

Айдар дүкенде 3 кг алма әр 450 ₸-ден және 2 л сүт әр 600 ₸-ден сатып алды. Ол 5 000 ₸-лік купюра берді. Кассир қайсы қайтаруы керек? Aidar buys 3 kg of apples at 450 ₸/kg and 2 L of milk at 600 ₸/L. He pays with 5 000 ₸. What's the change? Айдар купил 3 кг яблок по 450 ₸ и 2 л молока по 600 ₸. Он дал 5 000 ₸. Сколько сдачи?

📥 Input

  • a = 3 (кг)(kg)(кг)
  • pa = 450 ₸
  • b = 2 (л)(L)(л)
  • pb = 600 ₸
  • paid = 5000

🧮 Model

total = a*pa + b*pb change = paid - total

📤 Output

total = 2550 ₸
change = 2450 ₸
