💻 VM — не? 💻 What is a VM? 💻 Что такое ВМ?

Виртуалды машина (VM) — нағыз компьютер ішінде бағдарламалық түрде жасалған тағы бір компьютер. Оның өз CPU, жады, диск, желі картасы, тіпті өз ОЖ-і бар. Нақты «темір» болса hypervisor оны көп бөлікке бөледі — әр бөлік бөлек VM. Алғашқы тұжырым: 1960-шы жылдары IBM CP-40. Бүгін VM-сіз интернет жоқ: AWS, Azure, Google Cloud — миллиардтаған VM іске қосады. Үйде VM: VirtualBox, VMware Workstation, UTM (Mac). A virtual machine (VM) is another computer inside your computer, created by software. It has its own CPU, RAM, disk, NIC and even OS. A hypervisor slices the real hardware so each slice becomes a separate VM. Concept: IBM CP-40 in the 1960s. Today the internet runs on VMs: AWS, Azure, GCP spin up billions. At home: VirtualBox, VMware, UTM. Виртуальная машина (ВМ) — программно созданный компьютер внутри компьютера. У неё свой CPU, RAM, диск, сетевая карта и даже своя ОС. Настоящее «железо» нарезает гипервизор, каждый кусок — отдельная ВМ. Идея: IBM CP-40 в 1960-х. Сегодня весь интернет на ВМ: AWS, Azure, GCP поднимают миллиарды. Дома: VirtualBox, VMware, UTM.

🏛 Архитектура: Type 1 vs Type 2 🏛 Architecture: Type 1 vs Type 2 🏛 Архитектура: Type 1 vs Type 2

🖥 Type 1 (бұлт, дата-орталық) — гипервизор тікелей темірде, жылдамырақ. Type 2 (үйде) — әдеттегі ОЖ-дің үстінде, оңай орнату. 🖥 Type 1 (cloud, data-centre) runs directly on hardware — faster. Type 2 (home) sits on a host OS — easy to install. 🖥 Type 1 (облака, ЦОД) — гипервизор прямо на железе, быстрее. Type 2 (дома) — поверх обычной ОС, прост в установке.
