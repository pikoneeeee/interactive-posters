Quick Sort және Merge Sort

Quick sort & merge sort

Быстрая и слиянием сортировки

⚡ Неге «бөл және жаула»? ⚡ Why divide & conquer? ⚡ Почему «разделяй и властвуй»?

Пузырёк пен таңдау O(n²): 1 млн элемент 1 триллион әрекет. Quick Sort және Merge Sort — «бөл және жаула» (divide & conquer) идеологиясы: массивті екі бөлікке бөл, әрқайсысын рекурсивті шеш, содан қос. Күрделілігі O(n·log n) — 1 млн элемент небәрі 20 млн әрекет (50 000× жылдам). Bubble/selection are O(n²): 1 M elements ≈ 1 trillion ops. Quick Sort and Merge Sort use the divide-and-conquer idea: split the array into halves, sort each recursively, then combine. Complexity is O(n·log n) — only 20 M ops for 1 M elements (50 000× faster). Пузырёк и выбор — O(n²): 1 млн элементов ≈ 1 трлн операций. Quick Sort и Merge Sort используют «разделяй и властвуй»: массив делится пополам, каждая часть — рекурсивно, затем объединяется. Сложность O(n·log n) — 1 млн элементов = 20 млн операций (в 50 000× быстрее).

🔀 Merge Sort 🔀 Merge sort 🔀 Сортировка слиянием

1945 · John von Neumann — ең ескі O(n·log n) алгоритмі. Массивті екіге бөл, екеуін де сұрыпта, содан 2 реттелген тізбекті қос. the oldest O(n·log n) algorithm. Split in half, sort each half, merge two sorted halves. древнейший O(n·log n) алгоритм. Разделить пополам, отсортировать обе половины, слить две упорядоченные.

def merge_sort(a): if len(a) <= 1: return a mid = len(a) // 2 left = merge_sort(a[:mid]) right = merge_sort(a[mid:]) return merge(left, right) def merge(L, R): res, i, j = [], 0, 0 while i < len(L) and j < len(R): if L[i] <= R[j]: res.append(L[i]); i += 1 else: res.append(R[j]); j += 1 return res + L[i:] + R[j:]

⚡ Quick Sort ⚡ Quick sort ⚡ Быстрая сортировка

1960 · Tony Hoare — тірек (pivot) элементті таңдап, одан кіші және үлкен деп бөл. Одан екі жағын рекурсивті сұрыпта. Орташа — O(n·log n), ең жаманы — O(n²). pick a pivot, partition into <-pivot and >-pivot, sort each recursively. Average O(n·log n), worst O(n²). выбери «опорный» (pivot) элемент, раздели массив на меньше/больше pivot, каждую часть — рекурсивно. В среднем O(n·log n), худший — O(n²).

def quick_sort(a): if len(a) <= 1: return a pivot = a[len(a)//2] less = [x for x in a if x < pivot] equal = [x for x in a if x == pivot] greater= [x for x in a if x > pivot] return quick_sort(less) + equal + quick_sort(greater)
