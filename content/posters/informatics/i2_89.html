Классика: факториал и Фибоначчи

❗ Факториал — n! ❗ Factorial — n! ❗ Факториал — n!

n! = 1·2·3·…·n — бірінші n натурал санның көбейтіндісі. «!» леп белгісі тегін емес: Кристиан Крамп (1808) енгізді — математиктерді таңдандыратын жылдам өсуін көрсету үшін. 10! = 3 628 800, ал 20! ≈ 2.4·10¹⁸ — бүкіл Жердегі құмның саны! Келісім бойынша: 0! = 1. n! = 1·2·3·…·n — the product of the first n naturals. The «!» was introduced by Christian Kramp (1808) to show the astonishing growth. 10! = 3 628 800, 20! ≈ 2.4·10¹⁸ — more than grains of sand on Earth! By convention 0! = 1. n! = 1·2·3·…·n — произведение первых n натуральных. Знак «!» ввёл Кристиан Крамп (1808), чтобы подчеркнуть стремительный рост. 10! = 3 628 800, 20! ≈ 2.4·10¹⁸ — больше песчинок на Земле! По соглашению 0! = 1.

🔁 Итеративті шешімIterativeИтеративное

def fact(n): f = 1 for i in range(2, n + 1): f *= i return f print(fact(6)) # 720

🌀 РекурсивтіRecursiveРекурсивное

def fact(n): if n <= 1: return 1 return n * fact(n - 1) # fact(4) = 4·fact(3) = 4·3·2·1 = 24

🌀 Фибоначчи сандары 🌀 Fibonacci numbers 🌀 Числа Фибоначчи

Әр сан алдыңғы екеуінің қосындысы: F(n) = F(n-1) + F(n-2), F(0) = 0, F(1) = 1. Итальяндық Леонардо Пизан (Fibonacci) 1202 жылы қояндардың көбеюіне мысал келтірді. Бұл сандар табиғатта барлық жерде: күнбағыстың дәндері, қарағайдың бұтақтары, ұлулардың спиралі, алтын қатынас φ ≈ 1.618. Each number is sum of two before: F(n) = F(n-1) + F(n-2), F(0)=0, F(1)=1. Italian Leonardo of Pisa (Fibonacci) introduced the sequence in 1202 via a rabbit-breeding puzzle. These numbers appear in sunflower seeds, pine cone spirals, nautilus shells, and the golden ratio φ ≈ 1.618. Каждое число — сумма двух предыдущих: F(n) = F(n-1) + F(n-2), F(0)=0, F(1)=1. Итальянец Леонардо Пизанский (Фибоначчи) описал их в 1202 г. через размножение кроликов. Эти числа встречаются всюду: семена подсолнуха, шишки сосны, раковины моллюсков, золотое сечение φ ≈ 1.618.

🔁 O(n) — жылдамfastбыстро

def fib(n): a, b = 0, 1 for _ in range(n): a, b = b, a + b return a print(fib(30)) # 832040

🌀 Рекурсивті (баяу!)Recursive (slow!)Рекурсивное (медленное!)

def fib(n): if n < 2: return n return fib(n-1) + fib(n-2) # fib(40) ≈ 30 s!

⚠️ Рекурсия «қайталайды» — экспоненциалды баяу. @cache немесе итерация қажет. ⚠️ Naïve recursion recomputes — exponential. Use @cache or iteration. ⚠️ Рекурсия пересчитывает одно и то же — экспоненциальна. Применяй @cache или итерацию.

📐 Алтын қатынас 📐 Golden ratio 📐 Золотое сечение

F(n+1) / F(n) → φ ≈ 1.6180339887… (n → ∞). Бұл санды ежелгі грек сәулетшілері Парфенон-ды құрғанда пайдаланған. Фараон Хеопс пирамидасында да бар! F(n+1)/F(n) → φ ≈ 1.6180339887…. The ancient Greeks designed the Parthenon with it; even the Great Pyramid follows φ! F(n+1)/F(n) → φ ≈ 1.6180339887…. Древние греки строили по нему Парфенон, а пирамида Хеопса подчиняется φ!
