Есеп шешудің әмбебап жолы Universal problem-solving method Универсальный метод решения

Есеп шешу — шабыт емес, әдіс. 1945 жылы венгр математигі Дьёрдь Пойа «How to Solve It» кітабында 4 қадамды жариялады, олар бүгінге дейін жұмыс істейді: (1) есепті түсін, (2) жоспар құр, (3) жоспарды орында, (4) нәтижені тексер. Бұл 4 қадам кез келген тілде (Python, C++, JS) және кез келген деңгейде (мектеп есебінен Google бағдарлама-собеседованиеге дейін) қолданылады. Problem-solving is a method, not inspiration. In 1945 Hungarian mathematician George Pólya published 4 universal steps in «How to Solve It»: (1) understand, (2) plan, (3) execute, (4) verify. They work in any language (Python, C++, JS) and at any level — from school tasks to Google interviews. Решение задачи — это метод, а не озарение. В 1945 г. венгерский математик Дьёрдь Пойа в книге «Как решать задачу» сформулировал 4 шага, которые работают до сих пор: (1) понять, (2) спланировать, (3) выполнить, (4) проверить. Они подходят к любому языку (Python, C++, JS) и любому уровню — от школьной задачки до собеседования в Google.

🎯 1-есеп: Ең үлкен үш саннан 🎯 Task 1: Max of 3 numbers 🎯 Задача 1: Максимум из трёх чисел

📋 ШартTaskУсловие

Үш санды енгіз. Ең үлкенін шығар. max() қолданба! Read 3 numbers. Print the largest. Don't use max()! Ввести 3 числа. Вывести наибольшее. max() нельзя!

1. 👁 ТүсінуUnderstandПонять

Кіріс: 3 сан (a, b, c). Шығыс: 1 сан — ең үлкені. Мысал: 5 7 2 → 7 · 3 3 3 → 3. Input: 3 numbers (a, b, c). Output: largest. Examples: 5 7 2 → 7 · 3 3 3 → 3. Вход: 3 числа. Выход: наибольшее. Примеры: 5 7 2 → 7 · 3 3 3 → 3.

2. 📝 ЖоспарPlanПлан

a-ны «max» деп ал. b-ны салыстыр — үлкен болса max-қа жаз. c-мен де. Assume a is the max. Compare to b — replace if bigger. Same for c. Считаем a максимумом. Сравниваем с b — заменяем, если больше. То же с c.

3. 💻 КодCodeКод

a, b, c = map(int, input().split()) m = a if b > m: m = b if c > m: m = c print(m)

🎯 2-есеп: Кібісе жыл 🎯 Task 2: Leap year 🎯 Задача 2: Високосный год

📋 ШартTaskУсловие

Жылды енгіз. Кібісе ме екенін айт. Ереже: 4-ке бөлінсе — иә, бірақ 100-ге бөлінсе — жоқ, ал 400-ге бөлінсе — қайта иә. Is it a leap year? Rule: divisible by 4 → yes, by 100 → no, by 400 → yes again. Високосный ли год? Правило: делится на 4 — да, на 100 — нет, на 400 — снова да.

👁 МысалдарExamplesПримеры

2024 → ✅ · 2023 → ❌ · 2000 → ✅ · 1900 → ❌ · 2100 → ❌

# 2. бір құрама шартsingle conditionодно условие y = int(input()) leap = (y % 4 == 0 and y % 100 != 0) \ or y % 400 == 0 print("yes" if leap else "no")

🎯 3-есеп: Санның белгісі 🎯 Task 3: Sign of a number 🎯 Задача 3: Знак числа

3 санды енгіз. Олардың көбейтіндісінің белгісін анықта — көбейтусіз! Enter 3 numbers. Decide the sign of their product without multiplying! Введи 3 числа. Определи знак их произведения без умножения!

💡 ИдеяKey ideaИдея

Нөл бар болса — 0. Теріс сан саны жұп болса — «+», тақ болса — «−». Any zero → 0. Even count of negatives → «+», odd → «−». Если есть ноль → 0. Чётное число отрицательных → «+», нечётное → «−».

nums = list(map(int, input().split())) if 0 in nums: print("0") else: neg = sum(1 for n in nums if n < 0) print("+" if neg % 2 == 0 else "-")
