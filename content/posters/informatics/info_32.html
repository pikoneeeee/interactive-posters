1. Editor vs Processor

1. Редактор и Процессор

Текстовый редактор

Мәтіндік редактор

  • Только простой текст.
  • Нет картинок и оформления.
  • Тек қарапайым мәтін.
  • Суреттер жоқ.
  • Notepad (Блокнот)

Текстовый процессор

Мәтіндік процессор

  • Текст + Картинки + Таблицы.
  • Красивое оформление.
  • Мәтін + Сурет + Кесте.
  • Әдемі безендіру.
  • MS Word, Google Docs

2. Редакциялау және Пішімдеу

2. Editing and Formatting

2. Редактирование и Форматирование

✂️ Редактирование (Түзету)

Изменение содержания: исправление ошибок, копирование, удаление.

Мазмұнын өзгерту: қатені түзету, көшіру, өшіру.

🎨 Форматирование (Пішімдеу)

Изменение внешнего вида: шрифт, цвет, размер, выравнивание.

Түрін өзгерту: қаріп, түс, өлшем, туралау.

ЗАПОМНИТЕ

Редактор – жазу үшін, Процессор – безендіру үшін. "Қиып алу - Қою" (Cut-Paste) мәтінді жылжытуға көмектеседі.

Editor is for writing, Processor is for styling. "Cut-Paste" helps move text.

Редактор – для письма, Процессор – для оформления. "Вырезать - Вставить" помогает перемещать текст.
