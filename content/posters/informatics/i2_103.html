Екі өлшемді массив (матрица)

Two-dimensional array (matrix)

Двумерный массив (матрица)

Матрица — не? What is a matrix? Что такое матрица?

Екі өлшемді массив (матрица) — жол мен бағандан тұратын кесте. Әр элемент екі индекспен анықталады: a[i][j], мұнда i — жол, j — баған. Матрицаны Артур Кэли 1858 жылы математикаға енгізді. Бүгін ол барлық жерде: сурет (H×W×3 пиксель), шахмат тақтасы (8×8), Excel кестесі, нейрон желілерінің салмақтары, ойын картасы. Python-да — тізім ішіндегі тізім. A 2-D array (matrix) is a table of rows and columns. Each element has two indices: a[i][j], where i is the row, j is the column. Matrices were introduced by Arthur Cayley in 1858. They are everywhere: images (H×W×3 pixels), chess board (8×8), spreadsheets, neural-net weights, game maps. In Python it's a list of lists. Двумерный массив (матрица) — таблица из строк и столбцов. Каждый элемент задаётся двумя индексами: a[i][j], где i — строка, j — столбец. Матрицы в математику ввёл Артур Кэли в 1858 г. Сегодня они везде: изображения (H×W×3 пикс), шахматная доска (8×8), Excel, веса нейросетей, игровая карта. В Python — это список списков.
