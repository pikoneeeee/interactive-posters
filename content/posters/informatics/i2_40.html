Гиперссылки в документе

Гиперсілтеме дегеніміз не? What is a hyperlink? Что такое гиперссылка?

Гиперсілтеме (hyperlink) — басқа ресурсқа апаратын «басылатын» мәтін немесе сурет. «Hyper» = «үстем», «link» = «байланыс». Яғни, қарапайым текстің үстінде «көрінбейтін қабат» бар: оған басқанда — браузер ашылады, басқа бетке, файлға немесе e-mail-ге өтеді. Идеяны 1945 жылы Вэнивар Буш ойлаған, ал практикада 1989 жылы Тим Бернерс-Ли HTML құрғанда енгізген. Бүгінгі интернет гиперсілтемелер арқылы өмір сүреді — барлық веб-сайт бір-біріне сілтемелермен байланысқан. A hyperlink is clickable text or image that leads to another resource. «Hyper» = above, «link» = connection. Imagine an invisible layer on top of normal text: click it and the browser jumps to another page, file or e-mail. Proposed in 1945 by Vannevar Bush, implemented in 1989 by Tim Berners-Lee when he invented HTML. The whole internet lives on hyperlinks — every site is tied to others by links. Гиперссылка (hyperlink) — «кликабельный» текст или картинка, ведущая к другому ресурсу. «Hyper» = «сверх», «link» = «связь». Представь невидимый слой поверх обычного текста: кликнул — и браузер открывает другую страницу, файл или e-mail. Идея предложена в 1945 г. Ванневаром Бушем, реализована в 1989 г. Тимом Бернерсом-Ли в HTML. Весь интернет живёт на гиперссылках — сайты связаны друг с другом.

🛠 Word-та сілтеме қою 🛠 Adding a hyperlink in Word 🛠 Как добавить ссылку в Word

  1. 1 Сілтеме болатын мәтінді немесе суретті таңда.Select the text or image for the link.Выдели текст или картинку для ссылки.
  2. 2 Insert → Link немесеorили Ctrl+K
  3. 3 Диалогта мекенжайды жаз немесе файлды/бетбелгіні таңда.In the dialog type URL or pick a file/bookmark.В диалоге впиши адрес или выбери файл/закладку.
  4. 4 ScreenTip — курсорды апарғанда шығатын түсініктеме қос.— tooltip shown on hover.— подсказка при наведении.
  5. 5 OK. Сілтеме көк астасызылып пайда болады. Ctrl+Click — өту.OK. Link appears blue-underlined. Ctrl+Click to follow.OK. Ссылка синяя, подчёркнутая. Ctrl+Click — перейти.

📍 Құжат ішіндегі сілтеме: 2 тәсіл 📍 Link inside a document: 2 ways 📍 Ссылка внутри документа: 2 способа

1. Тақырыпқа (Heading)To a HeadingНа Heading (заголовок)

Алдымен мәтінге Heading 1/2/3 стилін қой, содан кейін сілтеме жасағанда «Place in this Document» → тақырыпты таңда.First apply Heading 1/2/3 style, then link → «Place in this Document» → pick heading.Сначала примени стиль Heading 1/2/3, потом при создании ссылки «Place in this Document» → выбери заголовок.

Ctrl+K → Place in this Document

2. Бетбелгі (Bookmark)BookmarkЗакладка (Bookmark)

Мәтіннің қалаған жеріне Insert → Bookmark қой (атау бер), содан кейін сілтеме жасағанда осы атауды көрсет.Place Insert → Bookmark anywhere, then link to that bookmark name.В любое место поставь Insert → Bookmark с именем, а потом сошлись на это имя.

Insert → Bookmark → «мой_абзац»
