Process modelling in Excel

Моделирование процессов в Excel

Модель — не? What is a model? Что такое модель?

Модель — шынайы құбылыстың «жеңілдетілген көшірмесі». Нағыз үйдің орнына — сурет-сызба, нағыз ауа-райының орнына — болжау формуласы. Excel-де модель = формулалар жиынтығы, ол «не болады, егер...?» деген сұрауға секундта жауап береді. Мысалы: «Жалақымды 15% өсірсем — жыл соңында қанша жинаймын?». Инженер жаңа көпірдің жүктемесін, экономист ел экономикасын, мектеп оқушысы зейнеткерлік қорын — бәрі Excel-мен модельдейді. A model is a «simplified copy» of reality. Instead of a real house — a blueprint; instead of real weather — a forecasting formula. In Excel, a model is a set of formulas that answer «what if…?» in seconds. «If salary grows 15% — how much do I save by December?». Engineers model bridge loads, economists model the national economy, students model pocket-money savings — all in Excel. Модель — упрощённая копия реальности. Вместо настоящего дома — чертёж, вместо настоящей погоды — формула прогноза. В Excel модель = набор формул, отвечающий за секунды на вопрос «что будет, если…?». «Если зарплата вырастет на 15%, сколько накоплю к декабрю?». Инженер моделирует нагрузку моста, экономист — экономику страны, школьник — копилку. Всё это — Excel.

Goal Seek

Excel кері есептейді: «нәтиже X болу үшін, кіріс қандай болу керек?» Reverse: «what input gives result X?» Обратное: «какой вход даст результат X?»

Data Table

Бір/екі параметрді өзгертіп, барлық нәтижені бір кестеге. Vary 1–2 inputs, see all outputs in one table. Варьирует 1–2 параметра, все результаты в одной таблице.

Scenario Manager

Бірнеше «жағдай» (сценарий) сақтап, арасында ауыстыру. Save multiple «scenarios» and switch. Сохраняет «сценарии» и переключает.
