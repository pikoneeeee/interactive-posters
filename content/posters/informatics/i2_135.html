🎨 CSS — не? 🎨 What is CSS? 🎨 Что такое CSS?

CSS (Cascading Style Sheets) — HTML элементтерінің көрінісін басқаратын тіл. 1996 жылы Håkon Wium Lie ұсынды. «Не» — HTML, «қалай көрінеді» — CSS. CSS каскад принципімен жұмыс істейді: бір элементке бірнеше ереже әсер етуі мүмкін, ең нақтысы жеңеді. CSS3-те: анимация, градиент, grid/flexbox, адаптив дизайн. CSS (Cascading Style Sheets) controls how HTML elements look. Invented by Håkon Wium Lie in 1996. HTML says «what», CSS says «how it looks». CSS cascades: several rules may apply, the most specific wins. CSS3 brings animations, gradients, grid/flexbox, responsive design. CSS (Cascading Style Sheets) — язык, описывающий внешний вид HTML-элементов. Придуман Хоконом Виум Ли в 1996 г. HTML — «что», CSS — «как выглядит». Работает по принципу каскада: несколько правил могут применяться, побеждает самое специфичное. В CSS3: анимации, градиенты, grid/flexbox, адаптивная вёрстка.

📦 Box Model 📦 Box model 📦 Блочная модель

Әр HTML элементі — «тартпа» (box): мазмұн + padding + border + margin. Бет — осы тартпалардан жиналады. Every HTML element is a box: content + padding + border + margin. A page is a stack of boxes. Каждый HTML-элемент — это «коробка»: content + padding + border + margin. Страница собирается из них.

.box { width: 300px; padding: 20px; border: 2px solid #0ea5e9; margin: 16px; box-sizing: border-box; /* width включает padding+border */ }

📱 Responsive / адаптив дизайн 📱 Responsive design 📱 Адаптивная вёрстка

Media queries — экран еніне қарай стильді өзгерту. Mobile-first тәсіл: алдымен ұсақ экран, одан үлкенге жетілдіру. Media queries change styles based on viewport width. Mobile-first approach: design for small first, enhance for larger. Media queries меняют стили в зависимости от ширины экрана. Подход mobile-first: сначала маленький экран, потом расширяем.

/* base — мобилка */ .grid { grid-template-columns: 1fr; } /* планшет */ @media (min-width: 640px) { .grid { grid-template-columns: repeat(2, 1fr); } } /* десктоп */ @media (min-width: 1024px) { .grid { grid-template-columns: repeat(4, 1fr); } }
