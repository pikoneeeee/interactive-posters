Архив дегеніміз не? What is an archive? Что такое архив?

Архив — бір немесе бірнеше файлды бір «қапқа» жинап, оны қысу алгоритмімен сығымдау. Кітап шкафын тыққыштап қораптағандай: кітаптар саны өзгермейді, бірақ орны үнемделеді. Қысу 2 идеяға сүйенеді: (1) қайталанатын деректерді қысқа кодпен алмастыру («ааа-ааа-ааа» → «3×ааа»), (2) жиі кездесетіндерге қысқа код беру (Huffman). Осы қатал математика соңғы 40 жылда файлдардың 50–80%-ын азайтуға мүмкіндік берді. An archive is one or more files packed into a single «container» and compressed. Like stuffing a wardrobe into a vacuum bag: the number of books doesn't change, but space shrinks. Compression uses 2 ideas: (1) replace repeated data with a short code («aaa-aaa-aaa» → «3×aaa»), (2) give frequent patterns shorter codes (Huffman). This math has shrunk files by 50–80% for 40+ years. Архив — это один или несколько файлов, упакованных в «контейнер» и сжатых алгоритмом. Как вакуумный пакет для одежды: вещей столько же, но места меньше. Сжатие — это 2 идеи: (1) заменить повторы короткими кодами («ааа-ааа-ааа» → «3×ааа»), (2) дать частым образцам коротке коды (Хаффман). Эта математика 40+ лет сжимает файлы на 50–80%.

💡 Маңызды фактKey factВажный факт

JPG, MP3, MP4, PDF — ішкі қысуы бар. Оларды ZIP/RAR-ға салса — өлшемі өзгермейді! Архив қою — тек біріктіру үшін. JPG, MP3, MP4, PDF are already compressed. Putting them in ZIP/RAR won't shrink them — archiving is only for bundling. JPG, MP3, MP4, PDF уже сжаты внутри. ZIP/RAR не уменьшат их — архив нужен только для объединения.

🔐 Парольді архив — қорғаныс 🔐 Password-protected archives 🔐 Архив с паролем — защита

Архивке AES-256 шифрлеуімен пароль қоюға болады. Паролді білмеу → файлдарды ашу мүмкін емес (заманауи суперкомпьютерге де миллиардтаған жыл керек). You can lock an archive with a password using AES-256. Without the password the files are unbreakable (even a supercomputer needs billions of years). Архив можно закрыть паролем с шифрованием AES-256. Без пароля файлы не открыть — суперкомпьютеру потребуются миллиарды лет.
