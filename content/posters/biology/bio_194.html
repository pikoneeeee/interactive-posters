🔌 Синапс механизмі:Synapse mechanism:Механизм синапса:

Пресинаптикалық аксон → Синаптикалық саңылау (20–50 нм) → Постсинаптикалық мембрана. Жүйке импульсі аксон терминалына жетеді → Ca²⁺ иондары кіреді → везикулалар нейромедиаторларды (ацетилхолин, дофамин, серотонин, ГАМК) бөледі → Рецепторлармен байланысады → Постсинаптикалық потенциал.
Қозыту (EPSP): деполяризация → жаңа импульс.
Тежеу (IPSP): гиперполяризация → импульс бастарын алады. ГАМК — негізгі тежеу медиаторы. Глутамат — негізгі қозыту медиаторы.Presynaptic axon → Synaptic cleft (20–50 nm) → Postsynaptic membrane. Impulse reaches axon terminal → Ca²⁺ enters → vesicles release neurotransmitters (acetylcholine, dopamine, serotonin, GABA) → bind receptors → postsynaptic potential.
Excitation (EPSP): depolarisation → new impulse.
Inhibition (IPSP): hyperpolarisation → suppresses impulse. GABA — main inhibitory transmitter. Glutamate — main excitatory transmitter.Пресинаптический аксон → Синаптическая щель (20–50 нм) → Постсинаптическая мембрана. Импульс достигает терминали → Ca²⁺ входит → везикулы выбрасывают нейромедиаторы (ацетилхолин, дофамин, серотонин, ГАМК) → связываются с рецепторами → постсинаптический потенциал.
Возбуждение (ВПСП): деполяризация → новый импульс.
Торможение (ТПСП): гиперполяризация → подавляет импульс. ГАМК — основной тормозной медиатор. Глутамат — основной возбуждающий медиатор.

🧠 ОЖЖ және ШЖЖ құрылымы:🧠 CNS and PNS structure:🧠 Структура ЦНС и ПНС:

ОЖЖ (Орталық жүйке жүйесі): Ми (үлкен ми — 4 бөлік: маңдай, қабыршақты, шүйде, самай; ми бағанасы; мишық; диэнцефалон) + Жұлын. ШЖЖ (Шеткі жүйке жүйесі): Краниалды нерв (12 жұп) + Жұлын нерві (31 жұп) + Сенсорлық рецепторлар. Глиалық жасушалар: Астроциттер (қоректендіру), Олигодендроциттер (миелин, ОЖЖ), Шванн жасушалары (миелин, ШЖЖ), Микроглия (иммундық).CNS (Central Nervous System): Brain (cerebrum — 4 lobes: frontal, parietal, occipital, temporal; brain stem; cerebellum; diencephalon) + Spinal cord. PNS (Peripheral Nervous System): Cranial nerves (12 pairs) + Spinal nerves (31 pairs) + Sensory receptors. Glial cells: Astrocytes (nourishment), Oligodendrocytes (myelin, CNS), Schwann cells (myelin, PNS), Microglia (immune).ЦНС (Центральная нервная система): Головной мозг (большие полушария — 4 доли: лобная, теменная, затылочная, височная; ствол; мозжечок; промежуточный мозг) + Спинной мозг. ПНС (Периферическая нервная система): Черепные нервы (12 пар) + Спинномозговые нервы (31 пара) + Сенсорные рецепторы. Глиальные клетки: Астроциты (питание), Олигодендроциты (миелин, ЦНС), Клетки Шванна (миелин, ПНС), Микроглия (иммунные).
