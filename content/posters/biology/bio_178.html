Линдеман ережесі (10% ережесі):Lindeman's rule (10% rule):Правило Линдемана (правило 10%):

Бір трофикалық деңгейдегі энергияның тек ~10% ғана келесі деңгейге беріледі. Қалған ~90% жылу ретінде, тыныс алуда, экскрецияда жоғалады. Сондықтан тамақ тізбектері ұзын болмайды (3–5 деңгей).Only ~10% of energy at one trophic level is transferred to the next. The remaining ~90% is lost as heat, respiration, excretion. That is why food chains are short (3–5 levels).Только ~10% энергии одного трофического уровня передаётся на следующий. Остальные ~90% рассеиваются в виде тепла, дыхания, экскреции. Поэтому пищевые цепи короткие (3–5 звеньев).

🔢 Сандар пирамидасыNumbers pyramidПирамида чисел

Әр деңгейдегі жалпы биомасса. Теңіздерде инверсияланады (фитопланктон < зоопланктон — жылдам айналым).Total biomass at each level. Can invert in oceans (phytoplankton < zooplankton — rapid turnover).Суммарная биомасса на каждом уровне. Может инвертироваться в морях (фитопланктон < зоопланктон).

⚡ Энергия пирамидасыEnergy pyramidПирамида энергии

Деңгейдегі энергия ағыны (кДж/м²/жыл). Ешқашан инверсияланбайды — физика заңдарымен анықталады. Ең нақты пирамида.Energy flow at each level (kJ/m²/yr). Never inverted — governed by laws of physics. Most accurate pyramid.Поток энергии на уровне (кДж/м²/год). Никогда не инвертируется — определяется законами физики. Наиболее точная пирамида.

  • ☀️ Фотосинтез: CO₂ + H₂O → C₆H₁₂O₆ + O₂ (С атмосферадан алынады)Photosynthesis: CO₂ + H₂O → C₆H₁₂O₆ + O₂ (C removed from atmosphere)Фотосинтез: CO₂ + H₂O → C₆H₁₂O₆ + O₂ (С изымается из атмосферы)
  • 🫁 Тыныс алу: C₆H₁₂O₆ + O₂ → CO₂ + H₂O (барлық организмдер)Respiration: C₆H₁₂O₆ + O₂ → CO₂ + H₂O (all organisms)Дыхание: C₆H₁₂O₆ + O₂ → CO₂ + H₂O (все организмы)

⚗️ Азот айналымы (N циклы)Nitrogen cycle (N cycle)Круговорот азота (цикл N)

  • 🌱 Азот бекіту (Фиксация): N₂ → NH₃/NH₄⁺. Биологиялық (Azotobacter, Rhizobium — бұршақ тамырында) және физикалық (найзағай) жолмен.Nitrogen fixation: N₂ → NH₃/NH₄⁺. Biological (Azotobacter, Rhizobium — in legume roots) and physical (lightning).Фиксация азота: N₂ → NH₃/NH₄⁺. Биологическая (Azotobacter, Rhizobium — клубеньки бобовых) и физическая (молния).
  • ⬆️ Нитрификация: NH₄⁺ → NO₂⁻ → NO₃⁻. Nitrosomonas, Nitrobacter бактериялары. Өсімдіктер NO₃⁻ сіңіреді.Nitrification: NH₄⁺ → NO₂⁻ → NO₃⁻. Nitrosomonas, Nitrobacter bacteria. Plants absorb NO₃⁻.Нитрификация: NH₄⁺ → NO₂⁻ → NO₃⁻. Бактерии Nitrosomonas, Nitrobacter. Растения поглощают NO₃⁻.
  • ⬇️ Денитрификация: NO₃⁻ → N₂ (газ). Анаэробты топырақ бактериялары атмосфераға N₂ қайтарады.Denitrification: NO₃⁻ → N₂ (gas). Anaerobic soil bacteria return N₂ to atmosphere.Денитрификация: NO₃⁻ → N₂ (газ). Анаэробные почвенные бактерии возвращают N₂ в атмосферу.
  • 🍂 Аммонификация: органикалық N → NH₄⁺. Сапротрофтар белоктарды, нуклеин қышқылдарын ыдыратады.Ammonification: organic N → NH₄⁺. Saprotrophs break down proteins, nucleic acids.Аммонификация: органический N → NH₄⁺. Сапротрофы разлагают белки, нуклеиновые кислоты.
