💧 Суда еритін гормондар (пептидтер):Water-soluble hormones (peptides):Водорастворимые гормоны (пептиды):

Инсулин, глюкагон, АДГ, СТГ, адреналин. Мембрана арқылы өте алмайды → плазмалық мембранадағы рецепторларға байланысады → аденилатциклаза → цАМФ (екінші хабаршы) → протеинкиназаны белсендіреді → жасуша реакциясы. Тез — секундтар ішінде.Insulin, glucagon, ADH, GH, adrenaline. Cannot cross membrane → bind plasma membrane receptors → adenylate cyclase → cAMP (second messenger) → activates protein kinase → cell response. Fast — within seconds.Инсулин, глюкагон, АДГ, СТГ, адреналин. Не могут пройти через мембрану → связываются с рецепторами плазматической мембраны → аденилатциклаза → цАМФ (второй мессенджер) → активирует протеинкиназу → ответ клетки. Быстро — в течение секунд.

🧈 Майда еритін гормондар (стероидтар):Lipid-soluble hormones (steroids):Жирорастворимые гормоны (стероиды):

Кортизол, тестостерон, эстроген, прогестерон, тироксин. Липидті мембрана арқылы өтеді → цитоплазмадағы немесе ядродағы рецепторлармен байланысады → ДНҚ-ға бекіп, транскрипцияны реттейді → белок синтезін өзгертеді. Баяу — сағаттар мен күндер.Cortisol, testosterone, oestrogen, progesterone, thyroxine. Cross lipid membrane → bind cytoplasmic or nuclear receptors → bind DNA, regulate transcription → alter protein synthesis. Slow — hours to days.Кортизол, тестостерон, эстроген, прогестерон, тироксин. Проходят через липидную мембрану → связываются с рецепторами в цитоплазме или ядре → связываются с ДНК, регулируют транскрипцию → изменяют синтез белков. Медленно — часы и дни.

🔄 Теріс кері байланыс (Negative feedback) — эндокриндік жүйенің негізі:Negative feedback — the foundation of the endocrine system:Отрицательная обратная связь — основа эндокринной системы:

Гипоталамус → Либерин → Гипофиз → ТТГ → Қалқанша без → Т₃/Т₄ → [артса] → Гипоталамус/Гипофизді тежейді Hypothalamus → Liberin → Pituitary → TSH → Thyroid → T₃/T₄ → [if excess] → Inhibits hypothalamus/pituitary Гипоталамус → Либерин → Гипофиз → ТТГ → Щитовидная → Т₃/Т₄ → [при избытке] → Тормозит гипоталамус/гипофиз

Оң кері байланыс — сирек: окситоцин (бала туу кезінде), ЛГ (жұмыртқа шығу алдында). Теріс байланыс гомеостазды сақтайды: гормон деңгейі шамадан аспауын қамтамасыз етеді.Positive feedback — rare: oxytocin (during childbirth), LH surge (before ovulation). Negative feedback maintains homeostasis: ensures hormone levels don't exceed normal range.Положительная обратная связь — редко: окситоцин (во время родов), всплеск ЛГ (перед овуляцией). Отрицательная связь поддерживает гомеостаз: обеспечивает ненарушение нормального диапазона гормонов.

📌 Сахарлы диабет — ең жиі эндокриндік ауру:📌 Diabetes mellitus — most common endocrine disorder:📌 Сахарный диабет — наиболее частое эндокринное заболевание:

1-тип (~10%): аутоиммундық. β-жасушалар жойылады → Инсулин мүлде жоқ → Инсулин егу қажет. 2-тип (~90%): инсулинге резистентілік (рецептор жауап бермейді). Семіздік, қозғалыссыздық тудырады. Диета + метформин + инсулин. Белгілері: Полиурия (несеп көп), полидипсия (шөл), полифагия (ас артады), салмақ азаю.Type 1 (~10%): autoimmune. β-cells destroyed → No insulin at all → Insulin injections required. Type 2 (~90%): insulin resistance (receptors don't respond). Caused by obesity, inactivity. Diet + metformin + insulin.
