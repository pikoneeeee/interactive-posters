🔄 Деталдау (деталирование)🔄 Detailing🔄 Деталирование

Деталдау — жинақ сызбасы бойынша әрбір бөлшекке жеке сызба жасау. Жалпы геометриядан жеке бөлшектерді шығарып, өлшемдерді анықтаймыз. Detailing — creating individual part drawings from an assembly drawing. Extract each part with all dimensions. Деталирование — выполнение чертежей отдельных деталей по сборочному чертежу. Извлекаем каждую деталь с полными размерами.

📋 Тәртібі📋 Procedure📋 Порядок

  1. 1. Жинақ сызбасын оқу, бөлшекті табуRead assembly drawing, locate the partПрочитать сборочный, найти деталь
  2. 2. Бөлшектің формасын анықтауDetermine the part's shapeОпределить форму детали
  3. 3. Қажетті видтарды таңдауChoose required viewsВыбрать необходимые виды
  4. 4. Барлық өлшемдерді қоюAdd all dimensionsНанести все размеры
  5. 5. Шероховатость, материал, дәлдікRoughness, material, toleranceШероховатость, материал, допуски
