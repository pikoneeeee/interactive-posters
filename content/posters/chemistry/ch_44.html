2. Свойства кислот

🔬 ФИЗИКАЛЫҚ: pH < 7 (шырын), суда еритінді, көрінінсіз рөлі

⚗️ ХИМИЯЛЫҚ:

✓ 2HCl + Zn → ZnCl₂ + H₂↑ (металл)

✓ 2HCl + CuO → CuCl₂ + H₂O (оксид)

✓ HCl + NaOH → NaCl + H₂O (негіз)

✓ 2HCl + CaCO₃ → CaCl₂ + H₂O + CO₂↑ (түз)

🔬 PHYSICAL: pH < 7 (sour), soluble in water, colorless usually

⚗️ CHEMICAL:

✓ 2HCl + Zn → ZnCl₂ + H₂↑ (metal)

✓ 2HCl + CuO → CuCl₂ + H₂O (oxide)

✓ HCl + NaOH → NaCl + H₂O (base)

✓ 2HCl + CaCO₃ → CaCl₂ + H₂O + CO₂↑ (salt)

🔬 ФИЗИЧЕСКИЕ: pH < 7 (кислые), растворимы в воде, обычно бесцветны

⚗️ ХИМИЧЕСКИЕ:

✓ 2HCl + Zn → ZnCl₂ + H₂↑ (металл)

✓ 2HCl + CuO → CuCl₂ + H₂O (оксид)

✓ HCl + NaOH → NaCl + H₂O (основание)

✓ 2HCl + CaCO₃ → CaCl₂ + H₂O + CO₂↑ (соль)

ЗАКЛЮЧЕНИЕ

Қышқылдар - H⁺ иондарын беридіңіз құрамдас (HₓA). Құрамасы: H + неметалл + O. pH < 7, шырын, суда еритінді. Күшті (HCl, H₂SO₄) және сәлсі (H₂CO₃). Реакциялары: металл, оксид, негіз, түз. Өндіктігінің: өндіктігінің және өндіктігінің!

Acids donate H⁺ ions (HₓA). Composition: H + nonmetal + O. pH < 7, sour, soluble in water. Strong (HCl, H₂SO₄) and weak (H₂CO₃). Reactions: metal, oxide, base, salt. Applications: industrial and practical!

Кислоты отдают H⁺ ионы (HₓA). Состав: H + неметалл + O. pH < 7, кислые, растворимы в воде. Сильные (HCl, H₂SO₄) и слабые (H₂CO₃). Реакции: металл, оксид, основание, соль. Применение: промышленное и практическое!
