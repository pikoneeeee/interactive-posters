3 қадам: молекулалық → толық ион → қысқа ион 3 steps: molecular → full ionic → net ionic 3 шага: молекулярное → полное ионное → краткое ионное

Мысал: NaOH + HCl → NaCl + H₂O 1) Молекулалық: NaOH + HCl → NaCl + H₂O 2) Толық ионды: Na⁺+OH⁻ + H⁺+Cl⁻ → Na⁺+Cl⁻ + H₂O 3) Қысқа ионды (бірдейлерді алып тастаймыз): OH⁻ + H⁺ → H₂O → Кез-келген күшті қышқыл + кез-келген сілті нейтрализациясы осылай жазылады!

Иондық теңдеуде кім ион, кім молекула? What stays ionic vs molecular? Что ионами, что молекулой?

Иондарға жазылады:Written as ions:Пишем ионами:

✅ Ерігіш тұздар: NaCl → Na⁺ + Cl⁻
✅ Күшті қышқылдар: HCl → H⁺ + Cl⁻
✅ Сілтілер: NaOH → Na⁺ + OH⁻✅ Soluble salts: NaCl → Na⁺ + Cl⁻
✅ Strong acids: HCl → H⁺ + Cl⁻
✅ Alkalis: NaOH → Na⁺ + OH⁻✅ Растворимые соли: NaCl → Na⁺ + Cl⁻
✅ Сильные кислоты: HCl → H⁺ + Cl⁻
✅ Щёлочи: NaOH → Na⁺ + OH⁻

Молекула ретінде қалады:Stays as molecule:Остаётся молекулой:

❌ Тұнба: AgCl↓, BaSO₄↓
❌ Газ: CO₂↑, H₂S↑, NH₃↑
❌ Су: H₂O
❌ Әлсіз электролиттер: CH₃COOH, NH₄OH❌ Precipitate: AgCl↓, BaSO₄↓
❌ Gas: CO₂↑, H₂S↑, NH₃↑
❌ Water: H₂O
❌ Weak electrolytes: CH₃COOH, NH₄OH❌ Осадок: AgCl↓, BaSO₄↓
❌ Газ: CO₂↑, H₂S↑, NH₃↑
❌ Вода: H₂O
❌ Слабые электролиты: CH₃COOH, NH₄OH

1) Тұнба түзілуі: AgNO₃ + NaCl → AgCl↓ + NaNO₃ Ag⁺ + Cl⁻ → AgCl↓ 2) Газ түзілуі: Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ CO₃²⁻ + 2H⁺ → H₂O + CO₂↑ 3) Су түзілуі (нейтрализация): NaOH + HNO₃ → NaNO₃ + H₂O OH⁻ + H⁺ → H₂O

⚖️ Реакция жүреді деген критерий⚖️ Criteria for reaction to proceed⚖️ Критерии протекания реакции

Иондық алмасу реакциясы қайтымсыз аяқталу үшін кемінде бірі қажет:
1️⃣ Тұнба түзіледі (↓)
2️⃣ Газ түзіледі (↑)
3️⃣ Нашар диссоциацияланатын зат (H₂O, äлсіз қышқыл/негіз) түзіледі Ionic exchange reaction goes to completion if at least one of:
1️⃣ Precipitate forms (↓)
2️⃣ Gas forms (↑)
3️⃣ Weakly dissociating substance (H₂O, weak acid/base) forms Реакция ионного обмена идёт до конца, если образуется хотя бы одно из:
1️⃣ Осадок (↓)
2️⃣ Газ (↑)
3️⃣ Слабодиссоциирующее вещество (H₂O, слабая к-та/осн.)
