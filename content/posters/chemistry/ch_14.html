2. Расчёт молярной массы - примеры

📝 МЫСАЛ 1: H₂O молекулалық массасы

H₂O = 2×H + 1×O

Mr(H₂O) = 2×1 + 1×16 = 2 + 16 = 18 ✓

📝 EXAMPLE 1: Molecular mass of H₂O

H₂O = 2×H + 1×O

Mr(H₂O) = 2×1 + 1×16 = 2 + 16 = 18 ✓

📝 ПРИМЕР 1: Молярная масса H₂O

H₂O = 2×H + 1×O

Mr(H₂O) = 2×1 + 1×16 = 2 + 16 = 18 ✓

📝 МЫСАЛ 2: CO₂ молекулалық массасы

CO₂ = 1×C + 2×O

Mr(CO₂) = 1×12 + 2×16 = 12 + 32 = 44 ✓

📝 EXAMPLE 2: Molecular mass of CO₂

CO₂ = 1×C + 2×O

Mr(CO₂) = 1×12 + 2×16 = 12 + 32 = 44 ✓

📝 ПРИМЕР 2: Молярная масса CO₂

CO₂ = 1×C + 2×O

Mr(CO₂) = 1×12 + 2×16 = 12 + 32 = 44 ✓

📝 МЫСАЛ 3: NaCl молекулалық массасы

NaCl = 1×Na + 1×Cl

Mr(NaCl) = 1×23 + 1×35.5 = 23 + 35.5 = 58.5 ✓

📝 EXAMPLE 3: Molecular mass of NaCl

NaCl = 1×Na + 1×Cl

Mr(NaCl) = 1×23 + 1×35.5 = 23 + 35.5 = 58.5 ✓

📝 ПРИМЕР 3: Молярная масса NaCl

NaCl = 1×Na + 1×Cl

Mr(NaCl) = 1×23 + 1×35,5 = 23 + 35,5 = 58,5 ✓

📝 МЫСАЛ 4: Ca(OH)₂ молекулалық массасы

Ca(OH)₂ = 1×Ca + 2×(O+H) = 1×Ca + 2×O + 2×H

Mr(Ca(OH)₂) = 1×40 + 2×16 + 2×1 = 40 + 32 + 2 = 74 ✓

📝 EXAMPLE 4: Molecular mass of Ca(OH)₂

Ca(OH)₂ = 1×Ca + 2×(O+H) = 1×Ca + 2×O + 2×H

Mr(Ca(OH)₂) = 1×40 + 2×16 + 2×1 = 40 + 32 + 2 = 74 ✓

📝 ПРИМЕР 4: Молярная масса Ca(OH)₂

Ca(OH)₂ = 1×Ca + 2×(O+H) = 1×Ca + 2×O + 2×H

Mr(Ca(OH)₂) = 1×40 + 2×16 + 2×1 = 40 + 32 + 2 = 74 ✓

ЗАКЛЮЧЕНИЕ

Салыстырмалы атомдық масса (Ar) = бір атомның салмағы. Салыстырмалы молекулалық масса (Mr) = бір молекуланың салмағы. Mr есептеу: 1) формула элементтерді анықта, 2) әр элементтің Ar масс табу, 3) индекстер көбейту, 4) барлықты қосу. H₂O=18, CO₂=44, NaCl=58.5, Ca(OH)₂=74!

Relative atomic mass (Ar) = mass of one atom. Relative molecular mass (Mr) = mass of one molecule. Calculate Mr: 1) identify elements in formula, 2) find Ar for each, 3) multiply by subscripts, 4) add all. H₂O=18, CO₂=44, NaCl=58.5, Ca(OH)₂=74!

Относительная атомная масса (Ar) = масса атома. Относительная молярная масса (Mr) = масса молекулы. Расчёт Mr: 1) определить элементы, 2) найти Ar каждого, 3) умножить на индексы, 4) сложить. H₂O=18, CO₂=44, NaCl=58,5, Ca(OH)₂=74!
