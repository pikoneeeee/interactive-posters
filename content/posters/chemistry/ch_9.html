2. Атомный номер и масса

🔢 АТОМДЫҚ НОМЕР (Z):
= Протондар саны ядрода
= Электрондар саны атомда
Мысалы: H=1, C=6, O=8, Na=11
Мағынасы: элемент анықтайды!

🔢 ATOMIC NUMBER (Z):
= Number of protons
= Number of electrons in atom
Example: H=1, C=6, O=8, Na=11
IMPORTANCE: defines element!

🔢 АТОМНЫЙ НОМЕР (Z):
= количество протонов
= количество электронов
Пример: H=1, C=6, O=8, Na=11
ЗНАЧЕНИЕ: определяет элемент!

⚖️ АТОМДЫҚ МАССА (A):
= Протондар + Нейтрондар
= Салыстырмалы атомдық масса
Мысалы: H≈1, C≈12, O≈16, Na≈23
ӨНДІКТІГІ: молекулалық масса есептеу!

⚖️ ATOMIC MASS (A):
= Protons + Neutrons
= Relative atomic mass
Example: H≈1, C≈12, O≈16, Na≈23
IMPORTANCE: calculate molecular mass!

⚖️ АТОМНАЯ МАССА (A):
= протоны + нейтроны
= относительная атомная масса
Пример: H≈1, C≈12, O≈16, Na≈23
ЗНАЧЕНИЕ: рассчитать молярную массу!

ЗАКЛЮЧЕНИЕ

Элемент - атом құрамындағы әр түрі (118 түрі). Периодтық таблица Менделеев элементтерді органайза-тайды. Топтар: металдар (~80), өндіктер (~17), галогендер (5), инертті газдар (6). Атомдық номер (Z) = протондар саны = элемент анықтайды! Атомдық масса (A) = протондар + нейтрондар = молекулалық масса есептеуде пайдалану. Мысалы: Na=11 (Z), Na=23 (A).

Element - type of atom (118 types). Periodic table organizes elements. Groups: metals (~80), nonmetals (~17), halogens (5), noble gases (6). Atomic number (Z) = protons = defines element! Atomic mass (A) = protons+neutrons = calculate molecular mass. Example: Na=11 (Z), Na=23 (A).

Элемент - вид атома (118 видов). Периодическая таблица Менделеева. Группы: металлы (~80), неметаллы (~17), галогены (5), благородные газы (6). Атомный номер (Z) = протоны = определяет элемент! Атомная масса (A) = протоны+нейтроны = расчёт молярной массы. Пример: Na=11 (Z), Na=23 (A).
