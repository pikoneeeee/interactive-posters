📝 МЫСАЛ 1: H₂ + O₂ → H₂O

Қадам 1: Атомдарды санау:

Сол жақ: 2H + 2O | Оң жақ: 2H + 1O

Қадам 2: теңестіру үшін коэффициент қосу:

2H₂ + O₂ → 2H₂O

Сол жақ: 4H + 2O | Оң жақ: 4H + 2O (теңесті!) ✓

📝 EXAMPLE 1: H₂ + O₂ → H₂O

Step 1: Count atoms (unbalanced):

Left: 2H + 2O | Right: 2H + 1O (UNBALANCED!)

Step 2: Add coefficients:

2H₂ + O₂ → 2H₂O

Left: 4H + 2O | Right: 4H + 2O (BALANCED!) ✓

📝 ПРИМЕР 1: H₂ + O₂ → H₂O

Шаг 1: Подсчитать атомы (не сбалансировано):

Слева: 2H + 2O | Справа: 2H + 1O (НЕ СБАЛАНСИРОВАНО!)

Шаг 2: Добавить коэффициенты:

2H₂ + O₂ → 2H₂O

Слева: 4H + 2O | Справа: 4H + 2O (СБАЛАНСИРОВАНО!) ✓

📝 МЫСАЛ 2: C + O₂ → CO₂

теңестіру: 1C + 1O₂ = 1CO₂

Сол жақ: 1C + 2O | Оң жақ: 1C + 2O (БАЛАНСТАЛДЫ!) ✓

📝 EXAMPLE 2: C + O₂ → CO₂

Balance: 1C + 1O₂ = 1CO₂

Left: 1C + 2O | Right: 1C + 2O (BALANCED!) ✓

📝 ПРИМЕР 2: C + O₂ → CO₂

Баланс: 1C + 1O₂ = 1CO₂

Слева: 1C + 2O | Справа: 1C + 2O (СБАЛАНСИРОВАНО!) ✓
