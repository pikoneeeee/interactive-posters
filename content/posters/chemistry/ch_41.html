2. FEATURES OF ORGANIC COMPOUNDS

2. Особенности органических соединений

✓ Көміртегі орталығы: Барлық органикалық заттарында C орналасқан

✓ Жоғары разнообразие: Миллиондай органикалық құрамдас

✓ Сәлсі реакциялары: Ыстық, қысым, катализатор қажет

✓ Ерік жану: Өндіктігінің жану реакциялары

✓ Carbon center: All organic contain C

✓ High diversity: Millions of organics

✓ Weak reactions: Need heat, pressure

✓ Easy burning: Combustion reactions

✓ Углеродный центр: Все содержат углерод

✓ Высокое разнообразие: Миллионы соединений

✓ Слабые реакции: Нужны тепло, давление

✓ Легко горят: Реакции горения
