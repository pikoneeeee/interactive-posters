Реактив Толленса дайындалуы + реакция Tollens' reagent preparation + reaction Подготовка реактива Толленса + реакция

1. Ag₂O дайындалуы: AgNO₃ + NaOH → AgOH↓ → Ag₂O 2. Аммиакты ерітінді: Ag₂O + 4NH₃·H₂O → [Ag(NH₃)₂]OH (Толленс реактиві) 3. Альдегидпен реакция (ыстық): RCHO + 2[Ag(NH₃)₂]OH → RCOONH₄ + 2Ag↓ + 3NH₃ + H₂O ✨ Тазаланған сынаптта — күміс айна!

Альдегид — тотықсыздандырғыш (Ag⁺ → Ag⁰ тотықсыздандырады). Кетон бұл реакцияны бермейді → альдегид пен кетонды ажырату үшін қолданылады! Aldehyde is a reducing agent (reduces Ag⁺ → Ag⁰). Ketone does not react → used to distinguish aldehyde from ketone! Альдегид — восстановитель (восстанавливает Ag⁺ → Ag⁰). Кетон не реагирует → используется для различения альдегида и кетона!
