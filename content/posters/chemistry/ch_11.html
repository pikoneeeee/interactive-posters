3. FORMULA RULES

3. Правила написания формул

1️⃣ Элемент белгісі + нөмір: H₂O (H + H + O), CO₂ (C + O + O), не H2O және C02!

1️⃣ Element symbol + number: H₂O (H + H + O), CO₂ (C + O + O), NOT H2O or C02!

1️⃣ Символ элемента + число: H₂O (H + H + O), CO₂ (C + O + O), не H2O или C02!

2️⃣ Цифр = индекс (төмен): NaCl (1 Na + 1 Cl, цифр жазылмайды), CaCO₃ (1 Ca + 1 C + 3 O)

2️⃣ Numbers = subscripts (lower): NaCl (1 Na + 1 Cl, numbers omitted), CaCO₃ (1 Ca + 1 C + 3 O)

2️⃣ Числа = индексы (нижние): NaCl (1 Na + 1 Cl, не пишутся), CaCO₃ (1 Ca + 1 C + 3 O)

3️⃣ Аббатындағы скобка: Ca(OH)₂ = 1 Ca + 2 (O + H) = 1 Ca + 2 O + 2 H

3️⃣ Brackets for groups: Ca(OH)₂ = 1 Ca + 2 (O + H) = 1 Ca + 2 O + 2 H

3️⃣ Скобки для групп: Ca(OH)₂ = 1 Ca + 2 (O + H) = 1 Ca + 2 O + 2 H

4️⃣ Формула = құрамы анықтайды: H₂O ≠ H₂O₂ (вода ≠ пероксид), CO ≠ CO₂ (моноксид ≠ диоксид)

4️⃣ Formula = determines composition: H₂O ≠ H₂O₂ (water ≠ peroxide), CO ≠ CO₂

4️⃣ Формула = определяет состав: H₂O ≠ H₂O₂ (вода ≠ пероксид), CO ≠ CO₂
