1. DEFINITION OF MOLAR VOLUME

1. Определение молярного объёма

📐 МОЛЯРЛЫҚ КӨЛЕМ (Vm):

Vm = V / n = 22.4 л/моль (ССҚ-та, т.б. 0°C және 101.3 кПа)

Бір моль кез келген газдың көлемі 22.4 литр!

📐 MOLAR VOLUME (Vm):

Vm = V / n = 22.4 L/mol (at STP, i.e. 0°C and 101.3 kPa)

One mole of any gas has volume 22.4 liters!

📐 МОЛЯРНЫЙ ОБЪЁМ (Vm):

Vm = V / n = 22.4 л/моль (при НУ, т.е. 0°C и 101.3 кПа)

Один моль любого газа имеет объём 22.4 литра!

2. Расчёты объёма

📝 МЫСАЛ 1: 0.5 моль O₂ көлемі неше?

V = n × Vm

V = 0.5 моль × 22.4 л/моль = 11.2 л ✓

📝 EXAMPLE 1: Volume of 0.5 mol O₂?

V = n × Vm

V = 0.5 mol × 22.4 L/mol = 11.2 L ✓

📝 ПРИМЕР 1: Объём 0.5 моль O₂?

V = n × Vm

V = 0.5 моль × 22.4 л/моль = 11.2 л ✓

📝 МЫСАЛ 2: 44.8 л CO₂ нешеше моль?

n = V / Vm

n = 44.8 л / 22.4 л/моль = 2 моль ✓

📝 EXAMPLE 2: How many mol in 44.8 L CO₂?

n = V / Vm

n = 44.8 L / 22.4 L/mol = 2 mol ✓

📝 ПРИМЕР 2: Сколько молей в 44.8 л CO₂?

n = V / Vm

n = 44.8 л / 22.4 л/моль = 2 моля ✓

ЗАКЛЮЧЕНИЕ

Молярлық көлем Vm = 22.4 л/моль (ССҚ-та). Формула: V = n × Vm немесе n = V / Vm. Кез келген газ (N₂, O₂, CO₂, H₂) ССҚ-та бірдей молярлық көлемге ие. Газ есептемелері өте жеңіл!

Molar volume Vm = 22.4 L/mol (at STP). Formula: V = n × Vm or n = V / Vm. Any gas (N₂, O₂, CO₂, H₂) has same molar volume at STP. Gas calculations very easy!

Молярный объём Vm = 22.4 л/моль (при НУ). Формула: V = n × Vm или n = V / Vm. Любой газ (N₂, O₂, CO₂, H₂) имеет одинаковый молярный объём при НУ. Расчёты газов очень просто!
