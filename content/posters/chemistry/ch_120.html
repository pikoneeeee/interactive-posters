ТД анықтау ережелері Oxidation State Rules Правила определения СО

• Жай зат: ТД = 0 (Fe⁰, Cl₂⁰)
• Иондар: ТД = заряд (Na⁺ = +1, Cl⁻ = −1)
• H: +1 (металл гидридтерінде −1)
• O: −2 (пероксидтерде −1, OF₂-де +2)
• F: −1 (барлық қосылыста)
• Металл: оң ТД (Na: +1, Ca: +2, Al: +3)
• Молекула ТД қосындысы = 0
• Ионда ТД қосындысы = заряд • Free element: SO = 0 (Fe⁰, Cl₂⁰)
• Monatomic ion: SO = charge (Na⁺=+1, Cl⁻=−1)
• H: +1 (−1 in metal hydrides)
• O: −2 (−1 in peroxides, +2 in OF₂)
• F: −1 (always)
• Metals: positive SO (Na:+1, Ca:+2, Al:+3)
• Sum of SO in molecule = 0
• Sum of SO in ion = charge • Простое вещество: СО = 0 (Fe⁰, Cl₂⁰)
• Ионы: СО = заряд (Na⁺=+1, Cl⁻=−1)
• H: +1 (−1 в гидридах металлов)
• O: −2 (−1 в пероксидах, +2 в OF₂)
• F: −1 (всегда)
• Металлы: положительная СО
• Сумма СО в молекуле = 0
• Сумма СО в ионе = заряд
