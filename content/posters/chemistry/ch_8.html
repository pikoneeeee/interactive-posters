Атомы и молекулы

Атом - ең кіші бөлінік зат. Молекула - атомдың біріктігі. 10-10 метр өлшемі! Электрон облак моделі!

Atom - smallest particle of matter. Molecule - union of atoms. 10⁻¹⁰ meters! Electron cloud model!

Атом - наименьшая частица вещества. Молекула - объединение атомов. 10⁻¹⁰ метров! Модель электронного облака!

1. АТОМ ҚҰРЫЛЫМЫ ЖӘНЕ МОДЕЛЬДЕРІ

1. ATOM STRUCTURE & MODELS

1. Структура атома и модели

⚛️ ТАРИХИ МОДЕЛЬДЕРІ:
1. Дальтон (1808): Атом - бөлінбейтін сфера (ақымы сыйпы)
2. Томсон (1897): Электрон - "құлпынды дәмі" моделі
3. Резерфорд (1909): Өздіктерінің орталығында ядро + электрон орбита
4. Бор (1913): Орбиталар - рөлі энергия деңгейі
5. Шредингер (1925): ЭЛЕКТРОН ОБЛАК моделі - әйтшісі ғалыми!

⚛️ HISTORICAL MODELS:
1. Dalton (1808): Atom - indivisible sphere
2. Thomson (1897): Electron - "plum pudding" model
3. Rutherford (1909): Nucleus + electron orbits
4. Bohr (1913): Energy levels
5. Schrödinger (1925): ELECTRON CLOUD - most scientific!

⚛️ ИСТОРИЧЕСКИЕ МОДЕЛИ:
1. Дальтон (1808): неделимая сфера
2. Томсон (1897): "плумпудинг"
3. Резерфорд (1909): ядро + орбиты
4. Бор (1913): энергетические уровни
5. Шредингер (1925): облако электронов!

⚛️ АТОМ ҚҰРАМЫ:
• Ядро: Протондар (+) + нейтрондар (0)
• Электрондар: (-) облакындағы уақыт орындалатын
• Өлшемі: ~10⁻¹⁰ метр (ангстрем!)
• Ядро өлшемі: ~10⁻¹⁵ метр (қатты жабық!)
• Жалпы массасы: 99.9% ядро деген!

⚛️ ATOM COMPOSITION:
• Nucleus: Protons (+) + Neutrons (0)
• Electrons: (-) electron cloud
• Size: ~10⁻¹⁰ m (angstrom!)
• Nucleus size: ~10⁻¹⁵ m (extremely dense!)
• Total mass: 99.9% nucleus!

⚛️ СОСТАВ АТОМА:
• Ядро: протоны (+) + нейтроны (0)
• Электроны: (-) электронное облако
• Размер: ~10⁻¹⁰ м (ангстрем!)
• Размер ядра: ~10⁻¹⁵ м (сверхплотное!)
• Общая масса: 99.9% ядро!

2. МОЛЕКУЛАЛАР ЖӘНЕ ҚАСИЕТТЕРІ

2. Molecules & Properties

2. Молекулы и их свойства

🔬 МОЛЕКУЛАЛАР:
✓ 2+ атом біріктігі
✓ Ковалент байланыста
✓ Зат табиғаты сақтайды
✓ Мысал: H₂O (су), O₂ (газ)

🔬 MOLECULES:
✓ Union of 2+ atoms
✓ Covalent bonds
✓ Preserve substance properties
✓ Example: H₂O, O₂

🔬 МОЛЕКУЛЫ:
✓ объединение 2+ атомов
✓ ковалентная связь
✓ сохраняют свойства
✓ Пример: H₂O, O₂

⚛️ АТОМДАР:
✓ Бір элементтің ең кіші бөлінік
✓ Өздіктерінің табиғатын сақтамайды
✓ Мысал: Натрий Na (метал)
✓ О₂ айырып O атом (**өткенді!**)

⚛️ ATOMS:
✓ Smallest particle of element
✓ Isolated = different properties!
✓ Example: Na atom (not metal)
✓ O atom from O₂ = reactive!

⚛️ АТОМЫ:
✓ наименьшая частица элемента
✓ изолированные = другие свойства!
✓ Пример: атом Na (не металл!)
✓ атом О из О₂ = активный!

ҚОРЫТЫНДЫ

CONCLUSION

ЗАКЛЮЧЕНИЕ

Атомдар - зат ең кіші бөлінігі (10⁻¹⁰ м). Құрамы: ядро (протон + нейтрон) + электрон облако. Модельдері эволюция: Дальтон → Томсон → Резерфорд → Бор → Шредингер (электрон облак - әйтшісі ғалыми!). Молекулалар - 2+ атом біріктігі ковалент байланысында. Молекула зат табиғаты сақтайды, ал атом сағындалмайды!

Atoms - smallest particles (10⁻¹⁰ m). Nucleus (proton+neutron) + electron cloud. Model evolution: Dalton → Thomson → Rutherford → Bohr → Schrödinger (electron cloud = most scientific!). Molecules - 2+ atoms united by covalent bonds. Molecule preserves substance properties, isolated atom = different!

Атомы - наименьшие частицы вещества (10⁻¹⁰ м). Ядро (протон+нейтрон) + облако электронов. Эволюция моделей: Дальтон → Томсон → Резерфорд → Бор → Шредингер (облако электронов). Молекулы - 2+ атомов с ковалентными связями. Молекула сохраняет свойства вещества!
