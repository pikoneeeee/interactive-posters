РНҚ-да: A–U жұбы (T орнына U). Комплементарлық принципі репликацияда, транскрипцияда қолданылады. In RNA: A–U pair (U instead of T). Complementarity is used in replication and transcription. В РНК: пара A–U (вместо T — U). Принцип комплементарности используется при репликации и транскрипции.

🔄 Репликация (ДНҚ → ДНҚ)Replication (DNA → DNA)Репликация (ДНК → ДНК)

ДНҚ тізбектері ажырайды → әр тізбек матрица ретінде қолданылады → комплементарлық принцип бойынша жаңа тізбек синтезделеді → 2 идентикалық ДНҚ DNA strands separate → each strand acts as template → new strand synthesised by complementarity → 2 identical DNA molecules Цепи ДНК расходятся → каждая служит матрицей → новая цепь синтезируется по комплементарности → 2 идентичные молекулы ДНК

📝 Транскрипция (ДНҚ → мРНҚ)Transcription (DNA → mRNA)Транскрипция (ДНК → мРНК)

ДНҚ тізбегі матрица → РНҚ-полимераза ферменті → мРНҚ синтезделеді. Мысал: ДНҚ: 3'-ААТЦГТ-5' → мРНҚ: 5'-УУГАЦУ-3' DNA strand is template → RNA polymerase enzyme → mRNA synthesised. Example: DNA: 3'-AATCGT-5' → mRNA: 5'-UUGACU-3' Цепь ДНК — матрица → фермент РНК-полимераза → синтез мРНК. Пример: ДНК: 3'-ААТЦГТ-5' → мРНК: 5'-УУГАЦУ-3'

⚙️ Трансляция (мРНҚ → Ақуыз)Translation (mRNA → Protein)Трансляция (мРНК → Белок)

мРНҚ рибосомаға келеді → тРНҚ кодонды таниды (3 нуклеотид) → аминқышқылын жеткізеді → пептидтік байланыс түзіледі → ақуыз тізбегі. 1 кодон = 1 амқышқыл. mRNA arrives at ribosome → tRNA recognises codon (3 nucleotides) → delivers amino acid → peptide bond forms → protein chain. 1 codon = 1 amino acid. мРНК приходит к рибосоме → тРНК распознаёт кодон (3 нуклеотида) → доставляет аминокислоту → образуется пептидная связь → белковая цепь. 1 кодон = 1 аминокислота.
