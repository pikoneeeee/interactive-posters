2. Примеры - полные уравнения

🔗 СИНТЕЗ:

C + O₂ → CO₂ (көмірқышқыл газының түзілуі)

2Mg + O₂ → 2MgO (Магнийге оттегісі)

🔗 SYNTHESIS:

C + O₂ → CO₂ (Carbon dioxide formation)

2Mg + O₂ → 2MgO (Magnesium oxide)

🔗 СИНТЕЗ:

C + O₂ → CO₂ (образование углекислого газа)

2Mg + O₂ → 2MgO (оксид магния)

⚡ ЫДЫРАУ:

2HgO → 2Hg + O₂ (сутегі оксидінің ыдырауы)

CaCO₃ → CaO + CO₂ (кальцийге оксидінің ыдырауы)

⚡ DECOMPOSITION:

2HgO → 2Hg + O₂ (mercury oxide)

CaCO₃ → CaO + CO₂ (calcium carbonate)

⚡ РАЗЛОЖЕНИЕ:

2HgO → 2Hg + O₂ (оксид ртути)

CaCO₃ → CaO + CO₂ (карбонат кальция)

🔄 АЙЫРБАСТАУ:

H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O (сутегі негіздің сілтілік талқыны)

HCl + NaOH → NaCl + H₂O (қышқылдың негіздік талқыны)

🔄 EXCHANGE:

H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O (neutralization)

HCl + NaOH → NaCl + H₂O (acid-base)

🔄 ОБМЕН:

H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O (нейтрализация)

HCl + NaOH → NaCl + H₂O (кислотно-основная)

➡️ ЫҒЫСТЫРУ:

Fe + CuSO₄ → FeSO₄ + Cu (темір құрамдасын ығыстырады)

Zn + 2HCl → ZnCl₂ + H₂ (сутегі ығыстыруы)

➡️ REPLACEMENT:

Fe + CuSO₄ → FeSO₄ + Cu (iron replaces copper)

Zn + 2HCl → ZnCl₂ + H₂ (hydrogen replacement)

➡️ ЗАМЕЩЕНИЕ:

Fe + CuSO₄ → FeSO₄ + Cu (железо заменяет медь)

Zn + 2HCl → ZnCl₂ + H₂ (замещение водорода)

ЗАКЛЮЧЕНИЕ

Төрт түрдегі реакциялар: 1) Синтез (A+B→AB), 2) Ыдырау (AB→A+B), 3) Айырбастау (AB+CD→AD+CB), 4) Ығыстыру (A+BC→AC+B). Әрбір түрінің өз мысалдары және ереді бар. Бұл төрт түрі барлық химиялық реакциялардың негіздері!

Four types of reactions: 1) Synthesis (A+B→AB), 2) Decomposition (AB→A+B), 3) Exchange (AB+CD→AD+CB), 4) Replacement (A+BC→AC+B). Each has examples and rules. These four types are the foundation of all chemical reactions!
