2. PRACTICAL EXAMPLES

2. Практические примеры

💨 НЕНАСЫЩЕННЫЙ ҰЗЫН

• Сулы құрамасындағы 50°C

• T < 100°C қайнау

• Төмен ығалдау

• Сұйық құрамасындағы

• Конденсация мүмкін

💨 UNSATURATED VAPOR

• Water vapor at 50°C

• T < 100°C boiling

• Low humidity

• No liquid phase

• Condensation possible

💨 НЕНАСЫЩЕННЫЙ ПАР

• Водяной пар при 50°C

• Т < 100°C кипения

• Низкая влажность

• Без жидкой фазы

• Конденсация возможна

💧 ЫЛЫҚТАЛҒАН ҰЗЫН

• Сулы құрамасындағы 100°C

• T = 100°C қайнау

• Максимум ығалдау

• Сұйық + газ қоспасындағы

• Деңсаулық сақталады

💧 SATURATED VAPOR

• Water vapor at 100°C

• T = 100°C boiling

• Maximum humidity

• Liquid + gas mixture

• Equilibrium maintained

💧 НАСЫЩЕННЫЙ ПАР

• Водяной пар при 100°C

• Т = 100°C кипения

• Максимальная влажность

• Жидкость + газ смесь

• Равновесие сохраняется

🔑 ІРІЛІ ҰСТАНУ: Ненасыщенный ұзын - төмен плотность, дөнгелек. Ылықталған ұзын - максимум плотность, деңсаулық. Фазалық өзгеру байланысты!

🔑 KEY POINTS: Unsaturated vapor - low density, can vary. Saturated vapor - max density, equilibrium. Phase transition related!

🔑 КЛЮЧЕВЫЕ МОМЕНТЫ: Ненасыщенный пар - низкая плотность, может изменяться. Насыщенный пар - макс плотность, равновесие. Связано с фазовым переходом!

CONCLUSION

ЗАКЛЮЧЕНИЕ

Ненасыщенный ұзын - төмен плотность, T < T_қайнау, сұйық құрамасындағы. Ылықталған ұзын - максимум плотность, T = T_қайнау, деңсаулық. Фізика ұзындарының!

Unsaturated vapor - low density, T < T_boiling, no liquid. Saturated vapor - max density, T = T_boiling, equilibrium. Physics of vapors!

Ненасыщенный пар - низкая плотность, Т < Т_кипения, без жидкости. Насыщенный пар - макс плотность, Т = Т_кипения, равновесие. Физика паров!
