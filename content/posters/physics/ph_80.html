1. КРИСТАЛДАНУ ПРОЦЕСІ

1. CRYSTALLIZATION PROCESS

1. Процесс кристаллизации

🔥 Балқу ПРОЦЕСІ

1. Қатты материал + жылу

2. Т = T_плав-ға өндіктігінең

3. Молекулалар ұрпақтары

4. Кристальды құрамасындағы - ломается

5. Сұйық құрамасындағы (chaotic)

🔥 MELTING PROCESS

1. Solid material + heat

2. T = T_melt increases

3. Molecules vibrate more

4. Crystal structure breaks

5. Liquid forms (chaotic)

🔥 ПРОЦЕСС ПЛАВЛЕНИЯ

1. Твёрдое + тепло

2. Т = T_плав растёт

3. Молекулы колеблются больше

4. Кристаллическая структура ломается

5. Жидкость образуется (хаос)

❄️ КРИСТАЛЛДАНУ ПРОЦЕСІ

1. Сұйық материал - охлаждение

2. Т = T_плав-ға төмен болады

3. Молекулалар жүрістеу

4. Ядралы құрамасындағы (seeds)

5. Кристаль құрамасындағы - әндіктігінең!

❄️ CRYSTALLIZATION PROCESS

1. Liquid material - cooling

2. T = T_melt decreases

3. Molecules slow down

4. Nucleation centers (seeds)

5. Crystal structure forms!

❄️ ПРОЦЕСС КРИСТАЛЛИЗАЦИИ

1. Жидкое - охлаждение

2. Т = T_плав понижается

3. Молекулы замедляются

4. Центры зародышей (семена)

5. Кристаллическая структура образуется!

Плавление: Solid + Q → Liquid | Кристаллизация: Liquid - Q → Solid

2. ПРАКТИКАЛЫҚ ҚОЛДАНУ

2. PRACTICAL APPLICATIONS

2. Практические приложения

💎 КРИСТАЛЬ ӨНДІКТІГІНІҢ:

1. Отливка металлов (темір, мыс, алюминий) - машина құрамасындағы

2. Мұз өндіктігінің - холодильник, заморозка

3. Гемс құрамасындағы - ағындарын өндіктігінең (алмаз, рубин)

4. Кристаль салтанатының - полупроводниковлар (кремний, германий)

💎 CRYSTAL FORMATION USES:

1. Metal casting (iron, copper, aluminum) - mechanical parts

2. Ice formation - refrigeration, freezing

3. Gemstones - crystallization (diamond, ruby)

4. Crystal semiconductors (silicon, germanium)

💎 ПРИМЕНЕНИЕ КРИСТАЛЛИЗАЦИИ:

1. Отливка металлов (железо, медь, алюминий) - машинные детали

2. Образование льда - холодильники, заморозка

3. Драгоценные камни - кристаллизация (алмаз, рубин)

4. Кристаллические полупроводники (кремний, германий)

🔬 ACELERATION МЕТОДЫ:

• Медленная охлаждение (slow cooling) - большие кристаллы

• Быстрая охлаждение (quick cooling) - маленькие кристаллы

• Посев (seeding) - заданное направление кристаллов

🔬 CONTROL METHODS:

• Slow cooling - large crystals

• Fast cooling - small crystals

• Seeding - controlled direction

🔬 МЕТОДЫ КОНТРОЛЯ:

• Медленное охлаждение - большие кристаллы

• Быстрое охлаждение - маленькие кристаллы

• Посев (seeding) - контролируемое направление

CONCLUSION

ЗАКЛЮЧЕНИЕ

Плавления және кристаллизация - обратные процессы. Плавления: solid + Q → liquid. Кристаллизация: liquid - Q → solid. Практика: металл отливка, мұз образование, геммстоун кристаллы. Молекулалар упорядочивают = кристальная структура!

Melting and crystallization are opposite processes. Melting: solid + Q → liquid. Crystallization: liquid - Q → solid. Practice: metal casting, ice formation, gemstone crystals. Molecules order themselves = crystal structure!

Плавление и кристаллизация - противоположные процессы. Плавление: твёрдое + Q → жидкое. Кристаллизация: жидкое - Q → твёрдое. Практика: отливка металлов, образование льда, кристаллы драгоценных камней. Молекулы упорядочиваются = кристаллическая структура!
