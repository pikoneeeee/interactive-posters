2. ЭНЕРГИЯ БАЛАНСЫ ДӘЛЕЛІ

2. ENERGY BALANCE PROOF

2. Доказательство баланса энергии

⚖️ САҚТАЛУ ПРИНЦИПІ: Өндіктігінің құрамасындағы барлық энергиялар = const. Түрлері өзгеріс, бірақ сақталды.

⚖️ CONSERVATION PRINCIPLE: Total energy in isolated system = const. Forms change, but total conserved.

⚖️ ПРИНЦИП СОХРАНЕНИЯ: Полная энергия в изолированной системе = const. Формы меняются, но итог сохраняется.

📐 МАТЕМАТИКАЛЫҚ: E_начальный = E_конечный | E_мех + E_терм + E_электр + ... = const

📐 MATHEMATICAL: E_initial = E_final | E_mech + E_therm + E_electric + ... = const

📐 МАТЕМАТИКА: E_начальная = E_конечная | E_мех + E_тепл + E_электр + ... = const

💡 ПРИМЕРЫ: Батарея сгорает → теплу выпускается (q). Ұйық құлсың → механическая энергия артады. Электр лампа → жылу + жарыру.

💡 EXAMPLES: Battery burns → heat released (q). Ball falls → mechanical increases. Electric lamp → heat + light.

💡 ПРИМЕРЫ: Батарея горит → тепло (q). Мяч падает → механика растёт. Электролампа → тепло + свет.

ЗАКЛЮЧЕНИЕ

Энергия сақталады және өзгереді. Сәулелену → жылу → механикалық → электр → жарыру. Барлығы байланысты, барлығы трансформируется, барлығы = const. Фундаменталды заң физика!

Energy conserved and transforms. Radiation → heat → mechanical → electric → light. All connected, all transforms, all = const. Fundamental law of physics!

Энергия сохраняется и трансформируется. Излучение → тепло → механическая → электрическая → свет. Всё связано, всё преобразуется, всё = const. Фундаментальный закон физики!
