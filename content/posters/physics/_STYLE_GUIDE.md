# STYLE GUIDE — «Физика»

Единое правило оформления для всех 125 плакатов физики (7–11 класс).
Дизайн — в стиле информатики, но в **индиго-палитре** с акцентами «энергии».

---

## 1. Обязательные правила

1. **Качество**: учебный материал. Формулы точные, единицы СИ, законы корректные.
2. **Структура**: header + 3–5 секций + footer (3-колоночный «Запомни»).
3. **Светлые тона**: индиго на белом, тёмный текст на светлом фоне.
4. **3 языка**: ru, kk (казахский), en — обязательно во всех текстовых блоках.
5. **Визуализации**: SVG-схемы, графики, формулы с цветовой подсветкой.
6. **Уровень языка**: соответствует классу (см. §7).

## 4. Готовые CSS-классы (в `_ph_style.css`)

- `.card`, `.card-accent`, `.card-warm`, `.card-emerald`, `.card-rose`, `.card-amber`
- `.formula` — блок формулы (тёмный фон, цветная подсветка)
  - `.var` (переменные), `.num` (числа), `.op` (операторы), `.unit` (единицы)
- `.unit-pill` — таблетка единицы измерения (Н, м, кг, А, В...)
- `.badge`, `.badge-emerald`, `.badge-rose`, `.badge-amber`
- `.tile`, `.tile-emoji` — плитка с эмодзи
- `.svg-wrap` — обёртка для SVG-схем
- `table.t` — таблицы

## 6. Визуализации

### Обязательно для:
- **Формул**: блок `.formula` с цветной подсветкой переменных.
- **Сил/векторов**: SVG со стрелками `marker-end`.
- **Схем**: блок-схемы, цепи, маятники, призмы.
- **Графиков**: ВАХ, S(t), V(t), графики газовых законов.

### Шаблон SVG (стрелка вектора):
```svg
<defs>
  <marker id="arr1" viewBox="0 0 10 10" refX="9" refY="5"
          markerWidth="8" markerHeight="8" orient="auto">
    <path d="M0,0 L10,5 L0,10 z" fill="#4f46e5"/>
  </marker>
</defs>
<line x1="X1" y1="Y1" x2="X2" y2="Y2" stroke="#4f46e5"
      stroke-width="3" marker-end="url(#arr1)"/>
```

## 7. Уровень языка по классам

### 7 класс — учебный (вводный)
- Простые определения, аналогии: «трение — как ладонь по столу».
- Формулы — простые (A=F·s, ρ=m/V).
- Больше визуала, эмодзи.

### 8 класс — учебный
- Полноценные формулы (η=Aпол/Aзатр × 100%, Q=cmΔt).
- Введение энергии и закона сохранения.
- Графики простые.

### 9 класс — учебный, точный
- Электричество, магнетизм, оптика — корректные схемы цепей и линз.
- Чертежи приборов (амперметр, вольтметр, дин-метр).
- Решения задач: «Дано / Найти / Решение / Ответ».

### 10 класс — академический
- Кинематика, динамика, МКТ, термодинамика.
- Полные формулы с векторами: F⃗=ma⃗, p⃗=mv⃗.
- Графики изопроцессов (изотерма, изобара, изохора).

### 11 класс — академический+
- Сложные формулы: q₁q₂/4πε₀r², F=qvBsinα, E=hν, E=mc².
- Атомная и ядерная физика — модели Бора, диаграммы распада.
- Полупроводники, фотоэффект, элементарные частицы.
