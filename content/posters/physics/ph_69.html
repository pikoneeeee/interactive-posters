1. Полные примеры расчётов

📌 ЕСЕПТЕУ 1: Су нагревание

ДАНО: m = 2 кг су, T₁ = 20°C, T₂ = 60°C, c = 4200 Дж/(кг·°C)

НАЙТИ: Q = ?

РЕШЕНИЕ:

1) ΔT = T₂ - T₁ = 60 - 20 = 40°C

2) Q = m × c × ΔT = 2 × 4200 × 40

3) Q = 336000 Дж = 336 кДж

✅ ЖАУАП: 336000 Дж немесе 336 кДж

📌 CALCULATION 1: Water heating

GIVEN: m = 2 kg water, T₁ = 20°C, T₂ = 60°C, c = 4200 J/(kg·°C)

FIND: Q = ?

SOLUTION:

1) ΔT = T₂ - T₁ = 60 - 20 = 40°C

2) Q = m × c × ΔT = 2 × 4200 × 40

3) Q = 336000 J = 336 kJ

✅ ANSWER: 336000 J or 336 kJ

📌 ЕСЕПТЕУ 2: Темір охлаждение

ДАНО: m = 5 кг темір, T₁ = 100°C, T₂ = 40°C, c = 460 Дж/(кг·°C)

НАЙТИ: Q = ?

РЕШЕНИЕ:

1) ΔT = |T₂ - T₁| = |40 - 100| = 60°C

2) Q = m × c × ΔT = 5 × 460 × 60

3) Q = 138000 Дж = 138 кДж

✅ ЖАУАП: -138000 Дж (жылу бөлінді)

📌 ЕСЕПТЕУ 3: Мыс нагревание (c табу)

ДАНО: m = 0.2 кг мыс, ΔT = 10°C, Q = 800 Дж

НАЙТИ: c = ?

РЕШЕНИЕ:

1) Формула: c = Q / (m × ΔT)

2) c = 800 / (0.2 × 10)

3) c = 800 / 2 = 400 Дж/(кг·°C)

✅ ЖАУАП: 400 Дж/(кг·°C) - мыс немесе булумса!

📌 CALCULATION 3: Find copper's c

GIVEN: m = 0.2 kg copper, ΔT = 10°C, Q = 800 J

FIND: c = ?

SOLUTION:

1) Formula: c = Q / (m × ΔT)

2) c = 800 / (0.2 × 10)

3) c = 800 / 2 = 400 J/(kg·°C)

✅ ANSWER: 400 J/(kg·°C) - copper!

2. STEPS FOR CALCULATION

2. Этапы расчёта

1️⃣ ДАНО: Барлық берілген мәндерді жазу (m, T₁, T₂, c)

1️⃣ GIVEN: Write all values (m, T₁, T₂, c)

1️⃣ ДАНО: Записать все значения (m, T₁, T₂, c)

2️⃣ НАЙТИ: Іздейтін мәнді белгілі (Q? c? ΔT? m?)

2️⃣ FIND: Determine what to find (Q? c? ΔT? m?)

2️⃣ НАЙТИ: Определить, что найти (Q? c? ΔT? m?)

3️⃣ ФОРМУЛА: Q = m × c × ΔT немесе c = Q/(m×ΔT)

3️⃣ FORMULA: Q = m × c × ΔT or c = Q/(m×ΔT)

3️⃣ ФОРМУЛА: Q = m × c × ΔT или c = Q/(m×ΔT)

4️⃣ ЕСЕПТЕУ: ΔT = T₂ - T₁ болсын, сосын Q есептеу

4️⃣ CALCULATION: First ΔT = T₂ - T₁, then calculate Q

4️⃣ РАСЧЁТ: Сначала ΔT = T₂ - T₁, потом Q

5️⃣ ЖАУАП: Соңғы мәнді және өлшем бірлігін жазу (Дж немесе кДж)

5️⃣ ANSWER: Write final value and unit (J or kJ)

5️⃣ ОТВЕТ: Написать ответ с единицей (Дж или кДж)

ЗАКЛЮЧЕНИЕ

Жылу мөлшері есептеуі - массасы, нақ жылусыйлығы, температура айырмасының көбейтіндісі. Q = m×c×ΔT. Әрқашан ΔT = T₂ - T₁ болсын есептеу. Нағевание - Q оң, охлаждение - Q теріс (жылу бөлінді)!

Heat calculation is product of mass, specific heat, temperature difference. Q = m×c×ΔT. Always calculate ΔT = T₂ - T₁ first. Heating - Q positive, cooling - Q negative (heat released)!

Расчёт теплоты - произведение массы, удельной теплоёмкости, изменения температуры. Q = m×c×ΔT. Всегда сначала ΔT = T₂ - T₁. Нагревание - Q положительно, охлаждение - Q отрицательно (выделяется тепло)!
