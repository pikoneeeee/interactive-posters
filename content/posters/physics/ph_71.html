2. ӨНДІКТІГІНІҢ ӨЛШЕУ ПРОЦЕСІ

2. MEASUREMENT PROCESS

2. Процесс измерения

1️⃣ ДАЙЫНДАУ: Сенсорлар құрамасындағы. Компьютер қосу. Бағдарлама ашу. Файл құру.

1️⃣ SETUP: Connect sensors. Turn on computer. Open software. Create file.

1️⃣ ПОДГОТОВКА: Подключить датчики. Включить компьютер. Открыть программу. Создать файл.

2️⃣ ӨНДІКТІГІНЕҢ: Сенсорлар су ағынына құйады. Нагревание/охлаждение қуат қосу. Компьютер өндіктігінең өндіктігінең.

2️⃣ HEATING: Insert sensors. Apply heat. Computer records data continuously.

2️⃣ НАГРЕВАНИЕ: Вставить датчики. Применить тепло. Компьютер записывает данные непрерывно.

3️⃣ ӨНДІКТІГІНЕҢ: 30-60 секунд. Деректер сақталды (100+ нәтиже/сек). Точность ±0.1°C. Время каждые 0.1 сек.

3️⃣ DURATION: 30-60 seconds. Data stored (100+ readings/sec). Accuracy ±0.1°C. Time interval 0.1 sec.

3️⃣ ПРОДОЛЖИТЕЛЬНОСТЬ: 30-60 секунд. Данные сохранены (100+ измерений/сек). Точность ±0.1°C. Интервал 0.1 сек.

4️⃣ ЕСЕПТЕУ: Бағдарлама автоматты есептеу c, Q, ΔT. График құрамасындағы. Қателеу анализі.

4️⃣ CALCULATION: Software auto-calculates c, Q, ΔT. Generates graphs. Error analysis.

4️⃣ РАСЧЁТ: ПО автоматически вычисляет c, Q, ΔT. Генерирует графики. Анализ ошибок.
