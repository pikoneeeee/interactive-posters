# Интерактивные плакаты → новое ядро v4 (QR-активация + шифрование контента)

Плакаты переведены со старой лицензии v2 (короткий ключ, контент открытым текстом)
на схему нового ядра: лицензия **v4 (Ed25519)** по **QR-коду** + контент в assets
**зашифрован** (AES-256-GCM) и расшифровывается в памяти ключом из лицензии. В
распакованном APK исходных плакатов больше нет.

## Что изменилось
- `Licensing.kt` — v4: проверка подписи Ed25519, ключ контента приходит внутри лицензии.
- `MainActivity.kt` — контент отдаётся через `shouldInterceptRequest` с расшифровкой
  в памяти (`https://appassets.androidplatform.net/...`); добавлен QR-флоу активации.
- `QrScanActivity.kt` + `activity_qr_scan.xml` — сканер (CameraX + ML Kit, офлайн).
- `activation_screen.html` — кнопка «📷 Сканировать QR-код» + приём строки `OL1-…`.
- `build.gradle.kts` — BouncyCastle + CameraX + ML Kit, ABI-фильтр, `VARIANT_ID` на flavor.
- `sync_content.py` + `oi_protocol.py` — шифрование контента и генерация `product_config.json`.

## Лицензирование (модель продаж сохранена)
- Каждый предмет = свой ключ (`variant_id`): ключ физики **не** откроет химию.
- Сборка `allsubjects` = ключ **«Все предметы»** (`variant 0`).
- Бесплатные предметы (`music`, `grafika`, `labor_girls`, `labor_boys`, `nvp`) —
  как раньше: без активации, контент НЕ шифруется.

Соответствие предмет→variant хранится в ТРЁХ местах и должно совпадать:
`sync_content.py` (`SUBJECT_VARIANTS`), `build.gradle.kts` (`VARIANT_ID`), бот (`PC_PRODUCTS`).

## Как собрать
1. Нужен `ecosystem.keys` экосистемы (мастер-ключ контента + публичный ключ).
   Скрипт ищет его: переменная `OI_KEYS` → `android/ecosystem.keys` →
   `D:\oi-orda-ecosystem\product-core\ecosystem.keys`. **Не коммитить** его.
2. На машине сборки: `pip install cryptography` (для шифрования контента).
3. Обычная сборка как раньше:
   ```
   python build_apks.py physics        # один предмет
   python build_apks.py allsubjects    # все предметы (ключ «Все предметы»)
   python build_apks.py all            # все APK
   ```
   `build_apks.py` сам вызывает `sync_content.py` → синхронизация + шифрование.

## Выдача лицензии (бот)
`/genqr` → «Интерактивные плакаты» → выбрать предмет (или «Все предметы») →
Device ID (кнопка на экране активации доски) → клиент → срок → бот пришлёт QR + строку.
На доске: «📷 Сканировать QR-код».

## ВАЖНО при переходе
- **Старые ключи v2 больше не работают** — это жёсткий переход. Уже активированным
  устройствам нужен новый QR-ключ v4 и новый APK (контент теперь зашифрован).
- Ключ экосистемы сейчас **тестовый** (тот же, что в QR-прототипе и на боте). Перед
  массовым продакшеном — сгенерировать настоящий мастер (`keygen init`), пересобрать
  плакаты и заменить ключ на боте. Тестовый ключ лежит в репозитории — для продаж не годится.
- Локальная сборка APK на этой машине не работает (AF_UNIX) — собирать на рабочей
  машине сборки или в CI.
